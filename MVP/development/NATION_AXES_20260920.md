## 0. 이 문서가 푸는 문제

D13이 4개국에 성향을 배정했지만 그것은 **형용사**다. "남부는 적극적"을 플레이어는 느끼지 못한다.
느끼게 하려면 **동사**가 필요하다. 아래 세 축이 그 동사다.

| | 상대가 | 내가 해야 하는 것 | 그래서 다른 것 |
|---|---|---|---|
| 동부 | 무난하다 | **형태를 정한다** | 방치해도 안 식는다 |
| 남부 | 밀어붙인다 | **속도를 늦춘다** | 방치하면 제일 빨리 떠난다 |
| 북부 | 오지 않는다 | **계속 간다** | 내가 안 가면 진전이 0 |
| 서부 | 위에 있다 | **커진다** | 아쉬운 티를 내면 손해 |

네 동사가 전부 다르면 사건 수가 달라도 입체적으로 느껴진다.
**경계:** 북부처럼 "차갑게 시작해 녹는" 모양을 넷 다에 씌우면 넷이 똑같아진다. 이것이 유일한 실패 모드다.

## 1. 축 1 — 드리프트: 방치하면 어디로 흐르는가

현재 모든 관계는 안 건드리면 **얼어 있다.** 이것이 가장 큰 구멍이다.

**틱 정의:** 사건 1건 = 1틱. 단 **그 사건의 주체가 아닌 국가에만** 누적한다.
(동부 사건을 처리하는 동안 남부·북부·서부의 idle이 1씩 오른다.)

| 국가 | 변수 | 방치 주기 | 변화 | 바닥 | 회복 난이도 |
|---|---|---|---|---|---|
| **동부** | `eastWarmth` | — | **없음** | — | — |
| **남부** | `southLeverage` | **2틱** | −1, `south_elsewhere` +1 | 2 | 어렵다 — 다른 상대를 찾는다 |
| **서부** | `westWarmth` | **3틱** | −1 | 4 | 느리다 |
| **북부** | `northContact` | **4틱** | −1 | **0** | 가능하나 느리다 |

**동부를 0으로 두는 것이 핵심이다.** 넷 다 식으면 그냥 관리 게임이 된다.
동부는 안 식는데 **그래서 방심한다** — 후반에 형태를 정해야 할 때 쌓아둔 것이 없다.
`east_idle >= 6`이면 "동부는 여전히 그대로다" 류의 안심 서술을 넣어 방심을 유도한다.

**주기를 다르게 두는 이유:** 남부 2 / 서부 3 / 북부 4는 체감 속도를 벌리기 위한 값이다.
남부는 제일 빨리 떠나고, 북부는 제일 느리게 식지만 **쌓는 것도 제일 느리다**(접촉 1회 = +1, 형태 확정에 3 필요).

**구현:** Ink는 정수만 쓰므로 `*_idle` 카운터를 두고 주기 도달 시 감소 + 리셋.

## 2. 축 2 — 해석: 같은 행동을 다르게 읽는다

플레이어는 행동 하나를 고른다. 나라마다 자기 렌즈로 읽는다.
선택지에 **stance 5종**을 붙이고(`즉답` `유보` `확인` `강경` `양보`), 대상국이 아래대로 반응한다.

### 2.0 설계 제약 — 정답표가 되면 실패다

> 05 §3.5 *같은 결과도 플레이어가 왜 원했는지 게임이 단정하지 않는다*
> 05 §6-2 *특정 현실 관계를 정답으로 못 박고 있지 않은가*
> `DESIGN_INTENT` §A *정답 공략이 목적이 아니다*

**공짜 `+`가 하나라도 있으면 그것이 정답이 된다.** 따라서 다음을 규칙으로 못 박는다.

1. **모든 칸은 얻는 것과 치르는 것을 함께 갖는다.** 치르는 값은 대개 **다른 통화**다 — 관계로 얻고 자원으로 치르거나, 자원으로 얻고 시간으로 치른다.
2. **게임은 무엇이 좋은 상태인지 말하지 않는다.** 관계가 깊어지는 것이 항상 이득이 아니다 — `spent`가 오르고 내정이 밀린다.
3. **한 나라의 최선이 다른 나라의 손해다.** 넷을 동시에 최적화할 자원이 없다.
4. **일관성이 개별 선택보다 세게 작동한다**(§2.2). 표를 외워도 나라마다 다르게 굴면 효과가 반감된다.

### 2.1 반응표 — 얻는 것 / 치르는 것

숫자는 화면에 나오지 않는다. 다음 사건의 **관찰 서술**로만 드러난다(§12.1).

| | **동부** — 공들여도 티가 안 난다 | **남부** — 기다려주지 않는다 |
|---|---|---|
| **즉답** | 답신이 빨라진다 / `spent`+1. **어차피 안 식으므로 얻는 것이 적다** | 관계 유지 / **다음 제안이 더 커진다** — 인력·국고 압박 |
| **유보** | 아무 일도 없다 / `east_idle` 누적 → 후반 형태를 정할 때 쌓인 것이 없다 | 자원 절약 / 2틱 뒤 **다른 상대를 찾는다** |
| **확인** | 자료 교환이 늘어 형태가 잡힌다 / `labor`−1, `spent`+1 | 조건을 알게 된다 / 확인하는 동안 **일정이 바뀐다** — 시간이 비용이다 |
| **강경** | 거리가 생긴다 / **`bounded`로 싸게 정리하는 길이기도 하다** | `southLeverage`↑, 조건 개선 / 관계 냉각 |
| **양보** | 관계가 깊어진다 / `treasury`−2. **동부는 기록만 남기고 보답하지 않는다** | 관계 ++ / 다음 제안이 **복리로** 커진다 |

| | **북부** — 내가 안 가면 0이다 | **서부** — 아쉬운 쪽이 우리다 |
|---|---|---|
| **즉답** | 얻는 것 없음 / 성급하게 읽혀 `northContact` 안 오름 | 빨리 처리된다 / 조급하게 읽혀 **다음 조건이 불리해진다** |
| **유보** | 자원 소모 0 / **진전 0. 북부는 먼저 오지 않는다** | 체면 유지 → 조건이 덜 불리 / 3틱 드리프트. **곡물이 먼저 바닥날 수 있다** |
| **확인** | `northContact`+1 / `spent`+1, `labor`−1. **세 번 해야 한다** | 정보를 얻는다 / **우리 사정이 드러난다** — leverage 상실 |
| **강경** | 충돌 루트가 열린다(그 자체로 하나의 루트) / `northContact`−2 | **대등해지는 유일한 길** / 지원 중단 → `grain`−3 |
| **양보** | 얻는 것 없음 / 의심받는다. **북부는 절차를 원하지 선물을 원하지 않는다** | 지원 유지 / 조항이 추가되고 `dependent`로 굳는다 |

### 2.2 일관성 보정 — 이것이 정답표를 깨뜨린다

반응은 stance **하나**가 아니라 `(stance × 지금까지의 습관)`을 읽는다.

| | 효과 | 상대의 반응 |
|---|---|---|
| 습관과 **일치** | 그대로 | — |
| 습관과 **어긋남** | **절반** | 상대가 이유를 궁금해한다 |

습관은 7축으로 판정한다(`initiative` 높음 = 먼저 움직이는 왕, `caution` 높음 = 재는 왕 …).

> `initiative`가 높던 왕이 갑자기 유보하면 — *"서부는 답을 기다리며 우리 쪽 사정을 물어왔다."*
> `caution`이 높던 왕이 유보하면 — *"서부는 늘 그렇듯 다음 일정만 적어 보냈다."*

**표를 외워도 소용이 적다.** 나라마다 최적 수를 골라 다니면 일관성이 깨져 전부 절반이 된다.
**일관된 왕이 되거나, 계산적인 왕이 되거나** — 그 선택 자체가 이 게임의 주제다.

### 2.3 서술 규칙 — 채점표로 읽히지 않게

1. **선택지에 stance 이름을 라벨로 달지 않는다.** 사건마다 다른 문장으로 쓴다.
2. **반응 서술은 관찰이지 채점이 아니다.** 좋은지 나쁜지는 플레이어가 판단한다.
   > *"북부가 우리 문서 형식을 그대로 따라 썼다."* — 온기인가 사무적인 거리인가. 게임은 말하지 않는다.
3. **어느 `form`이 좋은 결말인지 말하지 않는다.** `frozen`도 `bounded`도 실패가 아니다(D1).
4. 같은 사건에서 "착한 선택지"가 한눈에 보이면 다시 쓴다.

### 2.4 7축과의 연결 (D3)

stance는 대상국 반응과 **별개로** 7축에 누적된다.
`즉답`→initiative↑ / `유보`→caution↑ / `확인`→uncertainty↓·caution↑ / `강경`→selfProtection↑ / `양보`→reciprocity↑·warmth↑

누적된 7축이 §2.2의 습관 판정에 쓰인다. **한 나라에서 만든 습관이 다른 나라에서 다르게 읽힌다.**

## 3. 축 3 — 형태: 관계가 굳는 모양

`east_form`은 이미 있다. 넷 다 준다. **각국이 묻는 질문이 서로 다르다** — 온도 4개가 아니다.

| 국가 | 변수 | 묻는 것 | 3형 |
|---|---|---|---|
| 동부 | `east_form` | 얼마나 열어뒀나 | `open` / `formal` / `bounded` |
| 남부 | `south_form` | **누구 속도로 갔나** | `partner` / `contract` / `slowed` |
| 북부 | `north_form` | **얼마나 녹았나** | `quiet_trust` / `wary` / `frozen` |
| 서부 | `west_form` | **얼마나 대등해졌나** | `equal` / `traded` / `dependent` |

**엔딩(D6 최소 10종):** 3⁴ = 81 조합 중 실제 도달 가능한 것에서 10종 이상을 고른다.
내정 상태(국고·인력·민심)는 엔딩을 가르지 않고 **서술의 배경**만 바꾼다.
안쪽 층("내가 결정하지.")은 관계 결과와 무관하게 도달한다 — 조건 금지.

## 4. 공통 소모 `spent` — 관계끼리 경쟁시킨다

나라별 압력 변수를 따로 만들지 **않는다.** 네 나라가 같은 통 하나를 쓴다.

```
VAR spent = 0    // 밖에 쓴 총량. 어느 나라든 여기로 들어간다.
```

| 행동 | 비용 |
|---|---|
| `유보` | **0** |
| `즉답` / `확인` / `강경` / `양보` | +1 |
| 사절 파견 · 직접 방문 · 공물 등 큰 행동 | +2 ~ +3 |

**임계 `spent` = 4 / 8 / 12**를 넘을 때마다 내정 사건 1건을 강제로 끼운다.

### 4.1 이 하나가 여러 결정을 동시에 구현한다

- **D14** — *"연애나 인간관계에 신경쓸수록 나 자신을 못 챙기게 된다."* 통이 나라별로 따로면 이 고증이 성립하지 않는다. **총량이 하나여야 관계끼리 경쟁한다.**
- **플레이 타임 차이** — 방어적 플레이어는 `spent`가 안 오르고 내정이 멀쩡하지만, 드리프트로 관계가 전부 식어 **사건 수가 줄고 짧아진다.** 우호적 플레이어는 관계가 살지만 내정 사건이 붙어 **길어지고 문란해진다.** 규칙으로 강제하는 것이 아니라 두 축의 결과다.
- **카르덴** — 해금 조건이 `관계가 내부 소모를 만들기 시작`인데 셀 것이 없어 대사가 15줄로 제일 적었다. `spent`가 생기면 **할 일이 생긴다.**
- **`eastPressure`** — 폐기하지 않는다. 동부 서술 전용으로 남기고 `spent`는 전역으로 둔다.

### 4.2 `spent`는 자원이 아니다

`spent`는 **1층(선택 이력)**이다. 밖에 쓴 주의의 총량이고, 내정 사건의 **빈도**를 가른다.
국고·곡물·인력·민심은 **2층(왕국 상태)**이고 사건의 **내용**과 엔딩 배경을 가른다.
둘은 겹치지 않는다 — 서신 한 통은 국고를 안 쓰지만 주의는 쓴다.
2층 설계는 `KINGDOM_RESOURCES_20260920.md` 참고.
