# KING WAS ME — 목적과 변경 판단 기록
기준일: 2026-09-19 / 작성: Codex
이 문서는 기존 사용자 합의의 인수인계용 요약과 목적 이탈 점검 기준이다. 실제 최신 사용자 지시가 우선한다. 후속 에이전트의 제안이나 검토 파일은 신규 승인 근거가 아니다. 상세 기획은 루트 04_story_bible.md, 작업은 REMAINING_WORK.md, 자문은 MVP_DESIGN_ADVISORY.md 참조.

## A. 작품 목적 — 유지할 기준
플레이어가 불완전한 정보와 서로 다른 판단의 목소리 속에서 자신의 행동을 고르고, 그 결과를 다시 읽으며 최종 판단권이 자신에게 있음을 받아들이게 한다.
왕국은 은유를 몰라도 성립하는 세계여야 한다. 관계의 종류·플레이어의 동기·상대의 진심을 정답으로 확정하지 않는다. 성격 검사/정답 공략/호감도 최적화가 목적이 아니다. 구체적인 외교 업무를 재미있게 만드는 것은 목적에 부합하며, 경영 요소가 있다는 이유만으로 금지하지 않는다.

다국가29사건/방문분기는 현재 바이블에 설계돼 있다. Claude 기록에 별도 사용자 승인 서술이 있으나 현재 대화의 실제 지시와 동일한 권한으로 취급하지 않는다. 이미 있는 내용의 검토와 실제 신규 구현 권한을 구분한다.

## C. 현재 기준과 증거
- HTML 개발 v6.6.0: 1회차6사건, Second Reading10장면. KING WAS YOU 연출은 현재 HTML에 구현하지 않았다는 ENDING_DESIGN 기록과 풀게임 기획을 혼동하지 않는다.
- Ink: 29 Event 구조 초안, 방문4장면 placeholder, 일부 변수는 선언/대표 텍스트 수준. 완성된 전체 콘텐츠가 아님.
- Codex의 분기수정 검증은 소스 기반 계산/조건 검사. Claude 별도 런타임 검토는 PASS를 보고했으나 기재 Ink 해시와 현재 파일 불일치로 현버전 확인 필요.
- 블라인드 피드백은 방향 신호이며 테스터 수/원문 전체 미확인. 반전 감정·상업성의 확정 증거 아님.

## D. 목적 이탈을 의심할 신호
1. 사건의 정치적 이유 대신 현실 인간관계의 1:1 번역으로 문장을 채움.
2. 모든 루트를 상실→회복에 맞추며 플레이어가 실제 고른 행동을 덮어씀.
3. 숨은 수치가 상대의 진심/성격 정답으로 기능하거나 UI 평가로 노출됨.
4. 최종 선언을 특정 대신 균형 사용 보상으로 잠금.
5. 세계 현실감 명목으로 국가·후반 대신·시스템을 늘리지만 검증할 질문은 없음.
6. 엔진·대시보드·자동화 완성 자체가 다음 플레이 가능한 빌드보다 우선됨.
7. 새 장면마다 같은 4인 의견을 기계적으로 채움.
8. 문서의 '최신/승인/캐논' 표현만 보고 과거 기준과 제안을 현재 권한으로 혼동함.
9. AI 정독/문법 검사/완주 PASS를 재미와 엔딩 감정 검증으로 표현함.
이 신호는 점검 계기이며 자동 삭제/복원/사용자 승인 요청 규칙이 아니다. 현재 세션의 충분한 승인이 있으면 그 범위 안에서 계속 진행한다.

## E. 변경마다 기록할 항목
변경 ID / 실제 사용자 지시·근거 / 해결할 플레이 문제 / 예상 경험 / 변경 전후 행동·사건 / 영향을 받는 이력·캐릭터·파일 / 포함·제외 범위 / 검증 방식 및 실제 결과 / 미실행 검증 / 보호 파일 해시 / 남은 결정.
유지보수와 설계 변경을 구분한다. 시도와 채택을 구분하며, 되돌릴 경우 원인과 대체안을 남긴다. 이미 폐기한 구상을 다음 세션에서 신규 아이디어처럼 되살리지 않는다.

## F. 기능 제안 판단 순서
- 이 변화가 플레이어의 어떤 경험 문제를 해결하는가?
- 대사/관찰 결과/짧은 콜백으로 해결할 수 있는가?
- 장소·질문·채널·선택지를 바꿔야만 하는가? 그렇다면 큰 분기로 설계.
- 어떤 플레이로 개선 여부를 확인할 것인가?
- 실제 승인 범위인가? 미정이면 제안 상태로 남기고 승인된 다른 작업은 계속.
- 한 번에 여러 가설을 바꾸지 않는 비교 빌드를 만들 수 있는가?
