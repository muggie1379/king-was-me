# Codex 작업 기록 — v6.7.0 Kingdom First Slice

일자: 2026-09-19

## 사용자 의도

HTML MVP는 Codex가 설계 실험용으로 계속 제작하고, 실제 Unity 게임 구현은 Claude가 담당한다. 최초 기획의 핵심처럼 1회차 왕국 운영 자체가 즐거운지를 먼저 검증한다.

## 구현

기존 `KING_WAS_ME_MVP.html` v6.6.0은 변경하지 않았다. 새 `KING_WAS_ME_KINGDOM_SLICE.html`을 만들고 기존 동부 6사건 사이에 네 사건을 교차 배치했다.

1. 첫 장부 — 불일치 재고와 당일 배급
2. 북부의 횃불 — 불완전한 국경 정보
3. 남부의 수로 — 공사비와 장기 통행세 계약
4. 서부의 늦은 곡물 — 오래된 우방의 약속 불이행

1회차는 총 10사건이다. 각 신규 사건은 관계 은유 없이도 왕국의 내정·안보·계약·구호 문제로 성립하며, 생활 NPC가 사실과 업무상 요청을 전달하고 대신은 판단 렌즈를 제공한다. 선택 결과는 즉시 성공/실패 점수 대신 왕국에 남는 조건으로 서술한다.

## 범위 경계

- 29 Event 전체 구현 아님
- 실제 Unity 이식 기준 확정 아님
- 기존 개발판, blind_test, MVP 루트 보존본, _shared, _history 미수정
- 기존 2회차 10장면과 완결 엔딩은 비교·회귀용으로 유지
- 신규 사건은 현재 선택 직후 결과까지 구현. 국가별 장기 후속 회수는 플레이테스트 후 결정

## 자동 검증

격리 폴더: `verification/kingdom_slice_v0_1/`

- 두 스크립트 문법 PASS
- 1회차 10사건: 30단계 완주 PASS
- 2회차 10장면: 30단계 완주 PASS
- 2회차 시간 초과 대체 선택지와 엔딩 PASS
- 1회차 타이머 일시정지/복원과 반복 진입 PASS
- 1·2회차 강한 분기 및 동적 제목 기록 PASS
- 1회차 마지막 선택 7종 × 누적값 2종 = 14경로 PASS
- 2회차 완결 조합 126경로 PASS

처음 세 회귀 테스트의 실패는 격리 폴더 생성 후 테스트 하네스가 기존 상대경로를 찾은 것이 원인이었다. 격리 복사본만 새 HTML 상대경로와 1회차 마지막 사건 인덱스 9로 수정한 뒤 모두 PASS했다. 게임 코드 오류로 숨기지 않고 기록한다.

## 아직 검증하지 못한 것

- 실제 브라우저 시각 배치, 스크롤, 키보드 포커스
- 실제 플레이어가 국가를 구별하고 다음 사건을 궁금해하는지
- 신규 사건 선택이 후반에 충분히 회수되는지
- 10사건의 전체 플레이 시간과 반복 피로
- 2회차가 신규 네 사건을 반영해야 하는지

## 플레이테스트 질문

1. 반전 설명 없이도 왕국 상황이 궁금했는가?
2. 동부·북부·남부·서부를 서로 다른 문제로 기억했는가?
3. 어떤 결정에서 가장 오래 고민했는가?
4. 대신 중 한 명이 늘 정답처럼 보였는가?
5. 선택 결과가 다음 통치 조건으로 남았다고 느꼈는가?
6. 다음 계절을 계속 플레이하고 싶었는가?

## Unity 인계

Claude는 이 파일 전체를 그대로 이식하지 않는다. 플레이테스트에서 유효한 사건 순서, 선택 의미, 후속 회수만 Unity에 채택한다. 상태는 현재 `HTML 구현 / 기술 검증 완료 / 플레이테스트 필요 / Unity 채택 미정`이다.
