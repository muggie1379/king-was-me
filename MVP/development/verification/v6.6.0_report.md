## 검증 한계 및 다음 작업

실행 검증은 Node 모의 DOM 기반입니다. Codex 인앱 브라우저에서 로컬 HTML을 열려고 했으나 URL 보안 정책에 의해 거부됐고 우회도 금지됐습니다. 실제 브라우저 시각·스크롤·키보드 포커스·모바일 배치 검증은 완료하지 못했습니다.

서사 검토는 ENDING_DESIGN.md의 Claude 검토 요청을 참고하세요. 새 대화의 상대를 분리한 선택과 마지막 한마디의 정서적 누적은 사용자/독립 검토자가 판단해야 합니다.
