# 카르덴 등장 순서 핫픽스

일자: 2026-09-19

## 발견

사용자 브라우저 확인으로 `서부의 늦은 곡물`에서 카르덴이 공식 소개 장면인 `늦은 답신`보다 먼저 발언하는 문제가 발견됐다.

## 원인

Ink가 아니라 Codex가 새 HTML 세로 단면을 축약 구현하면서 생긴 전사 오류다. 원본 Ink는 Event 9 서부 사건에서 세르안만 발언하며, Event 11 진입 시 `karden_introduced = true`를 설정하고 카르덴을 소개한다. Ink의 Event 5도 카르덴 미소개 시 남부 상단 대표가 정보를 대신 전달하는 조건문을 갖고 있다.

## 수정

새 HTML의 서부 사건에서 조기 카르덴 발언과 수호관 의견 카드를 제거했다. 필요한 사실은 재무 담당자가 전달하고, 의견 카드는 세르안과 이미 소개된 리안이 담당한다. 카르덴의 첫 등장은 기존 `늦은 답신` 소개 장면으로 유지한다.
