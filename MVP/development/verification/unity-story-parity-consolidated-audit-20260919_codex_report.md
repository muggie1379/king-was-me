## 3. 통합 결론

현재 Unity판은 초기 기획의 핵심 철학과 29개 사건의 주요 분기를 잃지는 않았다. 왕은 마지막 장면 전까지 직접 말하지 않고, 동부 외 국가가 교차하며, 상대의 속마음이나 점수를 플레이어에게 확정적으로 보여주지 않는다.

하지만 현재 플레이 가능한 형태는 **완성된 서사형 MVP보다 Ink 문장 재생기와 선택 버튼에 가깝다.** HTML MVP에서 플레이어가 정보를 듣고, 대신들의 해석을 비교하고, 논쟁이 멎은 뒤 왕으로서 결정을 내리고, 그 결과를 관찰하는 흐름이 Unity에서 대부분 축소되었다.

따라서 가장 큰 위험은 기획의 철학적 Drift가 아니라 **구조와 연출의 이식 누락**이다. 29개 사건 구조를 다시 설계하기보다 Event 1~2 수직 슬라이스에서 원래 의사결정 루프를 먼저 복구해야 한다.

Claude는 29개 사건에서 대신 대사가 평균 약 2줄이며, E15·E22·E26에는 대신 대사가 없고 E23 외에는 선택 직후 aftermath가 거의 없다고 계측했다. 이는 Codex가 지적한 “분기 골격은 있으나 플레이 가능한 드라마가 부족하다”는 결론을 수치로 뒷받침한다.

## 5. 서로 보완되는 발견

### 5.1 Codex가 구체적으로 지적한 문제

1. E23의 마지막 회담 선택은 즉시 반응만 바꾸고 E24에서 다시 합쳐진다.
2. E25는 모든 경로에서 “목표를 달성하지 못했다”와 철수를 전제한다.
3. 초기 7개 내부 성향 축은 Ink에 선언되어 있지만 한 번도 갱신되지 않는다.
4. `KING WAS YOU`, 휴대전화, 빈 왕좌, 1인칭 이동이 일반 텍스트처럼 출력된다.
5. 대신들이 서로 논쟁하거나 왕을 오해하고 이를 정정하는 장면이 부족하다.

### 5.2 Claude가 구체적으로 지적한 문제

1. 시작 화면이 “당신은 왕/말하지 않음/결정함”을 미리 알려 반전을 프라이밍했으며, Claude가 3인칭 문구로 수정했다.
2. 설계 메모 5곳이 플레이어 텍스트로 노출된다.
3. 미등장 대신의 `? ? ?` 슬롯이 인원과 기능 목록을 미리 노출한다.
4. E09의 “서운함을 전한다”는 행동보다 감정을 선택하게 만드는 문구에 가깝다.
5. 원래 Event 1~2 수직 슬라이스로 확인하려던 왕의 침묵과 대신의 존재감이 검증되기 전에 전체 29개 사건과 에셋 작업이 진행됐다.

두 보고서의 판단은 충돌하지 않는다. 예를 들어 Claude는 내부 변수의 존재와 비노출을 확인했고, Codex는 그중 전역 7축이 실제로는 갱신되지 않는다는 점을 확인했다. 즉 **형식은 남았지만 시스템은 작동하지 않는다.**

## 6. 사용자 직접 피드백

사용자가 Unity판을 확인하며 다음 문제를 직접 지적했다.

1. HTML MVP에서는 대신들의 대화가 끝난 뒤 왕의 선택을 기다릴 때, 각 대신의 의견을 한 화면에서 종합해 보여줬다.
2. Unity판에는 이 선택 전 의견 종합 연출이 없다.
3. 그 외에도 HTML MVP에서 존재하던 연출이 다수 누락된 것으로 보인다.
4. HTML MVP에는 개발용 내부 계산과 이를 확인하는 화면이 있었으나 Unity판에서는 보이지 않는다.

이 피드백은 단순한 UI 취향 문제가 아니다. 대신의 서로 다른 관점을 비교한 뒤 자신의 결정을 내리는 것이 1회차의 핵심 플레이이므로, 의견 종합 화면의 누락은 게임 구조 자체의 축소다.

## 7. HTML MVP와 현재 Unity의 실제 흐름

### HTML MVP

```text
사건 제시
→ 현장 인물과 대신들의 대화
→ 대신별 최종 의견 카드
→ 대신들의 짧은 논쟁
→ 논쟁이 멎고 모두 왕좌를 바라봄
→ 왕의 선택
→ 선택 직후 관찰 가능한 결과
→ 왕실 기록
```

### 현재 Unity

```text
Ink 문장을 한 줄씩 같은 본문 영역에 교체 출력
→ 마지막 문장 종료
→ 선택 버튼 출력
→ 선택 문구를 왕실 기록에 추가
→ 다음 Ink 구간 진행
```

`StoryController`는 현재 Ink 구간의 문장을 `pendingLines`에 담고 `storyText` 하나에 차례로 교체 출력한다. 선택 시점에는 직전 대신 발언이 화면에서 사라진다. `GameHud`의 대신 카드는 초상화·이름·직함과 현재 발언자 강조만 담당하며 의견 본문을 보존하지 않는다.

## 8. 확인된 기능 및 연출 누락

### P0 — 핵심 플레이 구조

1. **사건 제목·설명 구분**: Unity에는 ACT와 사건 번호만 있고 사건 제목·설명 전용 영역이 없다.
2. **현장 사실과 대신 해석의 분리**: 현재는 모두 같은 텍스트 창에서 재생된다.
3. **선택 전 대신 의견 종합 패널**: 각 대신의 최종 의견을 동시에 비교할 수 없다.
4. **대신 간 논쟁(`courtExchange`)**: 개별 발언과 상호 반박의 화면 문법이 같다.
5. **왕의 결정을 기다리는 정적**: 논쟁 종료 후 왕좌를 바라보는 비트 없이 바로 버튼이 나타난다.
6. **선택 직후 aftermath**: 결과가 별도 단계로 구분되지 않는다.
7. **선택과 외부 결과의 연결 기록**: 왕실 기록에는 선택 문구만 남고 관찰된 결과는 남지 않는다.
8. **후반 관계 결과 분화**: E23의 선택이 E24·E25 관계 형태에 충분히 반영되지 않는다.

### P1 — 사건 표현과 페이싱

1. 사건별 화면 형식: 회의, 지도, 보고서, 서신, 축제, 방문, 이동, 브리지, UI 최소 회담이 동일한 텍스트 패널로 처리된다.
2. 시간 제한과 침묵: 타이머, 시간 만료, 침묵 확인, 상황 변화 후 선택지 교체가 없다.
3. 동적 사건 제목과 강한 분기 표시가 없다.
4. 진행률은 `사건 n/29` 텍스트뿐이며 시각적 진행 막대가 없다.
5. E26에서 왕국 전체 지도를 다시 보여주는 장면 기능이 없다.
6. 선택 없이 결과만 관찰하는 브리지와 일반 대화가 같은 방식으로 재생된다.
7. 결과 화면과 전체 행동 회고가 없다.

### P1 — 반전과 엔딩

1. `재상 → 분석`처럼 잠깐 잘못 보이는 제한적 `reframe-bleed`가 없다.
2. `KING WAS YOU`가 전용 타이틀 장면으로 분리되지 않는다.
3. 휴대전화가 소품/화면으로 나타나지 않는다.
4. 빈 왕좌가 실제 카메라 장면으로 표현되지 않는다.
5. 왕좌까지 걷고 앉는 1인칭 이동이 없다.
6. 마지막 대사 전 정적과 공간음 설계가 없다.

### P0 — 개발자 도구와 내부 상태

HTML MVP에는 `개발용 내부 상태 보기`가 있었고 다음을 표시했다.

- `initiative`, `caution`, `reciprocity`, `pressure`, `selfProtection`, `uncertainty`, `warmth`
- `choiceHistory`
- 현재 사건 변형과 분기 라벨
- 침묵 횟수
- 늦은 답신·강한 분기의 판정 근거

현재 Unity Ink에는 두 종류의 값이 있다.

1. **선언만 되고 갱신되지 않는 7개 전역 축**: initiative, caution, reciprocity, pressure, selfProtection, uncertainty, warmth
2. **실제로 갱신되는 국가별 값과 플래그**: eastWarmth, eastPressure, northTension, southLeverage, westWarmth, coastalFamiliarity, pause_contact, north_hardline, south_hardline, royal_visit 등

Unity `StoryController`는 대신 등장 여부 외에는 이 값을 개발자에게 보여주지 않는다. 따라서 선택이 어떤 값을 바꿨는지, 현재 어떤 분기가 활성화됐는지, 다음 변형이 왜 선택됐는지를 즉시 검사할 수 없다.

복구할 개발자 패널 항목:

```text
현재 사건과 Ink 경로
최근 선택 ID
선택 이력
국가별 관계 상태
활성화된 강한 분기
등장한 대신
최근 선택으로 변한 값
다음 분기 판정 근거
```

전역 7축은 전부 되살리는 것이 목적이 아니다. 실제 분기에 쓰는 값만 남기고, **history first, stats second** 원칙에 따라 구체적 선택 이력을 우선해야 한다.

## 9. 현재 Unity에 존재하는 기능

- 현재 캐논 29개 사건 진행

## 11. 권장 Unity 사건 상태 구조

```text
TITLE
→ INTRO
→ DIALOGUE
→ ADVISOR_SUMMARY
→ COURT_EXCHANGE
→ ROYAL_PAUSE
→ CHOICE
→ AFTERMATH
→ CHRONICLE
→ NEXT_EVENT
```

특수 사건은 다음 상태를 선택적으로 삽입한다.

```text
TIMER
SILENCE
MAP
LETTER
TRAVEL
GLITCH
ENDING
```

현재 Unity는 사실상 `DIALOGUE → CHOICE` 두 단계에 가깝다. 누락 기능의 공통 원인은 개별 이미지나 버튼 부족보다 **사건을 여러 단계로 재생하는 상태 구조가 없는 것**이다.

## 13. Go / No-Go
