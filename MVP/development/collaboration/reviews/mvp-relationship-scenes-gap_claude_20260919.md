# MVP 대신 관계 장면 누락 분석 (Claude, 2026-09-19) — 사용자 피드백 "너무 정적이고 딱딱한 왕실회의 게임"

## MVP(HTML)가 관계를 보여주던 4가지 장치 (코드 근거: KING_WAS_ME_KINGDOM_SLICE.html)
1. **사건 도입부의 대신 간 대화** (`intro` 비트): 예) 공동 축제 — 리안 "지금부터는 약속보다 서로가 얼마나 더 머무는지를", 발렌 "아니, 분위기도 보고서에 기록합니까?", 세르안 "때로는 숫자보다 더 중요한 정보가 됩니다". 사건 시작부터 대신들이 서로 받아치며 성격이 드러난다.
2. **의견 뒤의 논쟁** (`courtExchange`, 16회): 예) 세르안 "우호 신호라는 데는 동의합니다. 약속으로 읽지는 마십시오." -> 리안 "약속이라 부르지 않겠습니다. 다만 상대가 먼저 움직였다는 사실도 지우진 않겠습니다." 서로의 말을 인용하며 동의/반박.
3. **선택 후 aftermath 반응** (`aftermath`, 선택지마다 3~4비트, MVP 57 / Slice 78회): 같은 결과를 대신마다 다르게 해석해 관계가 드러난다. 예) 발렌 "속도가 붙는군요. 폐하께서 결론을 앞당기고 싶으신 걸 수도" / 리안 "아니면 상대의 한 걸음에 같은 정도로 답하신 걸 수도" / 세르안 "둘 다 가능성입니다. 그 이상은 아직 모르지요." 그리고 상대국 사절 대사와 결과 서술로 끝난다.
4. **선택에 붙는 결과 기록(log)과 회고**: 왕실 기록이 "무엇을 했는지 + 관찰된 결과"로 남고 엔딩 회고가 이를 읽는다.

## Unity 현재 상태
- Ink에는 위 1~3이 거의 없다: 대신 대사 59줄(사건당 평균 2.0), 논쟁/aftermath 반응 없음. 그래서 Unity가 아무리 좌석 뷰를 만들어도 "의견 카드 → 선택"만 반복되는 정적인 회의가 된다.
- 문제의 뿌리는 화면이 아니라 **콘텐츠의 형태**: 관계 장면은 "대사 데이터 + 그 대사를 보여주는 연출" 두 층이 모두 필요하다.

## 제안: 관계 장면을 Unity 고유 연출로 (MVP 복제 아님)
콘텐츠(Codex, MVP 데이터에서 이식/재작성) — Ink 태그 후보:
- `# phase: exchange` 논쟁 비트 + `# to: <id>`(누구에게 말하는가) + `# stance: agree|counter|tease|worry`(관계 톤; 수치 아님)
- 선택지 뒤 `# phase: aftermath` 반응 비트(대신별 해석 2~3줄) + 상대국 반응 + 결과 서술
연출(Claude, Unity):
1. 논쟁: 화자 대신이 앞으로 기울고 **청자 쪽으로 몸/시선이 돌아간다**(좌우 반전/포즈 전환), 청자는 반응 표정 컷(고개 끄덕임/눈썹/한숨). 대사는 큰 팝업, 말이 끊길 때 카메라가 살짝 이동.
2. 대신 간 "관계선": 발언 때 두 사람 사이에 가는 시선선/하이라이트가 이어진다(동의=밝게, 반박=흔들림). 수치/호감도 표시는 금지(§12.1), 톤만.
3. aftermath: 선택 직후 **컷인**(대신 3인 표정 컷을 짧게 교차) -> 각자 해석 팝업 -> 상대국 사절 등장 컷 -> 장면 전환(디졸브/페이드) -> 기록에 결과 추가.
4. 사건 도입 컷씬: 사절 입장(문 열림, 회의장 조명 변화), 서류 도착(손에서 탁자로), 편지 열람 클로즈업 등 사건별 1~2개 연출 템플릿.
5. 정적(RoyalPause) 이후 연출: 선택 확정 순간 모든 시선이 이동하는 컷(왕의 결정이 반응을 일으킨다).
6. 타이머/침묵 사건(E13): 시계·촛불·사절 퇴장 카운트다운 연출.

## 필요한 것 (Codex)
- 예시 인게임 스크린샷(사용자가 요청함, 대기 중) — 위 컷/팝업/관계 연출의 시각 기준.
- 대신 표정/포즈 세트(청자 반응, 말하는 자세, 몸을 돌림), 사절/상대국 인물 컷, 사건별 컷 일러스트 몇 장.
- Ink 콘텐츠: 사건별 exchange/aftermath 이식(MVP 16 exchange, 57~78 aftermath 대사 참고). §30 Do Not Drift 준수(대신 감정 확정/호감 표시 금지).
