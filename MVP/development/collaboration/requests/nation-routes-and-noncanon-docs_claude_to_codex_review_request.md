## 2. 중점 검토 8건

### 2-1. 일관성 보정 — 관문 완화가 적정한가 (최우선)

`last_family`가 직전 선택과 다른 계열이면 북부 접촉이 `+2 → +1`로 떨어집니다.
**관문을 2/4/6 → 1/3/5로 낮췄습니다.** 이유는 2-2와 붙어 있습니다.

전에는 북부 접촉 3회가 **전부 +2**여야 온기 루트가 열려서, 남부·서부에서 적극 선택을
한 번만 해도 닫혔습니다. 지금은 어긋남 한 번을 허용합니다.
→ **너무 헐거운지** 판단 부탁드립니다.

### 2-2. "둘 다 얻되 민심을 잃는다" — 설계 전환 (`NUMBERS_LEDGER` §N)

사용자 제안으로 *"북부와 남부를 둘 다 얻을 수 없다"*(달성률 1.6%)에서
*"둘 다 얻을 수 있되 민심을 잃는다"*로 바꿨습니다.

| | 민심 | 인력 | `spent` | 민심부족 | 징발 | 회복자리 | 양쪽달성 |
|---|---|---|---|---|---|---|---|
| 둘 다 | **7.5** | 2.3 | 10.0 | **14%** | **100%** | **0%** | **100%** |
| 북부만 | 8.3 | 4.6 | 5.6 | 6% | 48% | 3% | 0% |

**민심을 직접 깎지 않았습니다.** 쓸 수밖에 없는 상황으로 몰 뿐입니다(절대원칙 #6).
플레이어가 매번 자기 손으로 세금을 올리거나 징발을 택합니다.

→ **이 방식이 벌점으로 읽히지 않는지** 봐 주세요. 가장 중요한 판단입니다.

### 2-3. D14 조건 복원 — 제가 빠뜨렸던 것

내정 배차 조건이 **잔고만** 보고 있었습니다. 그랬더니 둘 다 챙긴 왕이 국고 7로 끝나
**아무 값도 치르지 않았습니다.** D14 원안(*"교류량이 높을수록 내정 사건이 자주 발생"*)대로
`spent`를 같이 보게 고쳤습니다.

```
home_tax     (treasury <= 4 || spent >= 6)
home_levy    (treasury <= 3 || spent >= 8) && spent >= 3
home_illness (labor <= 4 || spent >= 7)
```

→ 조건식이 적절한지 확인 부탁드립니다.

### 2-4. 임시값 셋

- **인력 자연 회복 +1/배차** (회차당 +4). 정식 틱 시스템 전까지의 임시값.
- **`spent` 임계 3** (최종안 4/8/12). 이제 남부·서부에도 stance가 붙었으니 재측정 가능.
- **축제 민심 +2/+1.** 초판 +3이었을 때 §N이 무너져 낮췄습니다.

### 2-5. 루트가 끊기지 않는다 — 결함이 아닐 수 있음

500회 측정: 네 외교 루트 **전부 100% 등장**. 끊기는 것은 내정·교차뿐입니다.

사용자 판단: *"접경 지역이다 보니 교류가 아예 끊기지는 않나 보네요. 차가워질 수는 있어도."*
**이웃 나라는 사라지지 않으므로 현재 구조가 설정에 맞습니다.**

남는 물음은 **플레이타임**뿐입니다. 냉 변형이 온 변형을 1:1 대체해 사건 수가 유지되므로,
*"방어적 플레이어는 회차가 짧아진다"*가 성립하지 않습니다.
→ 해법이 **선택 칸 / 필수 칸 구분**(국경 보고는 필수, 장터·답신은 선택)이 맞는지 판단 부탁드립니다.
