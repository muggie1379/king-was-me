## 2. 스토리 표현 및 남은 설계
- 동부 E06/08/10/22의 독립적인 외교 목적(행사 공동 주최, 선물 관례, 자원 전달 이유)을 보강할 필요. 은유를 제거해도 정치·경제 사건으로 성립해야 함.
- E22 '사랑도 외교도 비쌉니다'는 후보 대사라 현재 실행 순서에서는 Fool 미소개로 나오지 않지만 원문에 남음. 채택 여부 검토.
- E28 '뭐해?' 대사는 이번 수정으로 회의록 대사로 바뀜. 과거 Claude 남은 작업 목록의 해당 지적을 그대로 새 작업으로 중복 등록하지 않음. 에필로그 유머의 반복 강도는 별도 판단.
- 생활 NPC 캐스팅/반복 등장/이전 선택 결과 작성. 인간의 장기처럼 각자 기능을 수행하되 특정 NPC=장기 매칭표·왕의 감정 판정·정책 결론 대행은 금지(§3.1 적용됨).
- Watcher 후속 참석 장면/보고 내용, Chaplain·Fool 상세 장면, 나머지 후반 대신 실제 채택 수는 미정. introduced/unlocked/현장 참석을 구분.
- 국가별 결과 표현 수, 실제 군사충돌 루트 존재 여부, 서부·남부·북부·해안 장기서브플롯, 국가명/문화/외형은 TBD.
- E29 국가 동적 선택은 보류 제안이며 자동 채택하지 않음.
- 관계 결과 E24의 실제 분기/텍스트 회수는 아직 구조 초안 수준. 일부 선언 변수의 의미와 실제 사용처도 정리 필요.

## 3. MVP 확장·검증 — 사용자 결정이 필요한 것
- 29 Event를 HTML 전체에 구현할지, 1~2개 타국 사건만 개발 MVP에 넣어 다국가 리듬을 검증할지 결정. 현재 승인된 수정이 풀게임 제작 승인을 뜻하지 않음.
- Full Game Second Reading은 핵심 선별/압축/1회차 이력 반영형 중 선택 필요. 29사건 전부 반복으로 고정하지 않음.
- 새 배열이 은유의 발견 시점을 늦추고 생활 NPC가 현실감을 높이는지는 실제 플레이테스트 필요. AI 정독·런타임 PASS가 감정 테스트를 대신하지 않음.
- 1회차 타이머 되돌리기 유지/변경은 아직 판단 항목. blind_test v6.5.3은 그대로 보존.
- Unity 착수/이식 범위는 별도 결정. HTML/Ink에서 사건 연결 안정화 후 검토.

## 4. 문서·협업 유지보수 (낮은 우선순위)
- 루트 안내 문서의 '블라인드 테스트 미실시', 과거 30분 설정 문구와 최신 기록을 구분/정리. 최초 설정 기록 자체를 없애지 않음.
- 루트 바이블의 상단 §17 및 §19→§21, 존재하지 않는 §19-1 링크는 이번 수정으로 정리됨. 재발 여부만 확인. _shared의 같은 이름 22사건 바이블은 구버전 참고이며 임의 수정/이동 금지.
- Claude 런타임 검토의 '양쪽 모두 잠금 없이 수정' 서술은 Codex acquire/release 수행 기록과 불일치. 상대 기록은 덮어쓰지 않고 실제 작업 로그 기준으로 대조할 필요.
- 완료된 과거 검토 10건이 scan pendingReviews로 남음. 대상/해시/잔여사항을 확인한 뒤 한 건씩 digest 완료 처리. pending은 결함10건이라는 뜻이 아님.
- 대시보드 실제 화면의 잘림/가독성 시각 검증은 미완료. 타이머는 창 시작 기준 예상 주기이며 실제 다음 예약시각은 미연결.
- 사용량 자동 조회/주기 요청 실제 처리 연결, 작업중 표시의 전체 앱 감지 범위는 아직 제한됨. 단일 협업 잠금 밖 활동을 감지한다고 주장하지 않음.
- 방치 잠금 20분은 의심 기준 잠정안. 자동 해제 금지, 소유자/실행 여부 확인과 사용자 확인 필요.
- Claude 직접 메시징 탐색은 종료된 항목: 기존 요청 파일 방식을 유지. 재시도 작업으로 등록하지 않음.
