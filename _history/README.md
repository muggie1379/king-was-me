# history 폴더 — 버전 관리 규칙

이 폴더는 과거 버전들의 스냅샷 보관용입니다.

## 규칙

- **`E:\KING WAS ME\KING_WAS_ME_MVP.html`(루트)** = 항상 "현재 최신" 버전. 파일명에 버전 번호를 안 붙이고 계속 덮어쓰는 작업 파일.
- **`E:\KING WAS ME\history\`** = 과거 버전들의 스냅샷. 새 버전이 루트 파일을 덮어쓰기 직전(또는 직후)에, 덮어써지기 전 버전을 `KING_WAS_ME_MVP_vX.Y.Z.html` 형식(구체적인 버전명은 그 버전의 dev-history 주석에 적힌 이름을 따름)으로 이 폴더에 복사해서 남겨둡니다.
- 지금 시점 기준 최신 버전은 **v6.5.2** (Title Resolution Hotfix)이고, 그 스냅샷을 `KING_WAS_ME_MVP_v6.5.2.html`로 이 폴더에 넣어뒀습니다.

## 참고 (이 컴퓨터 관련 제약)

이 폴더에 파일을 쓰는 Claude(Cowork) 세션은 이 컴퓨터에서 셸 접근 권한이 없어서, 파일을 새로 만들거나 덮어쓸 수는 있지만 **이동/삭제는 못 합니다.** 그래서 "버전 관리"는 이동이 아니라 **복사(스냅샷)** 방식으로 이루어집니다 — 루트 파일은 그대로 최신으로 남고, history 폴더에 그 시점 사본이 추가되는 식.

## diff 활용

버전 간 실제로 뭐가 바뀌었는지 확인하려면, `verification/extract.js`로 두 버전에서 각각 script1.js/script2.js를 뽑아서 `diff`를 떠보세요 (`verification/README.md`의 "claimed 범위 검증 습관" 섹션 참고). GPT가 "이것만 바꿨다"고 말한 범위와 실제 diff가 일치하는지 확인하는 습관은 계속 유지하는 걸 권장합니다.
