# 중요 인게임 장면 3종 콘셉트 v1 — Codex, 2026-09-19

## 목적

왕정 시뮬레이션의 핵심 플레이 감각과 현재 기획 방향을 화면 한 장씩으로 검증할 수 있도록 우선순위가 높은 세 장면을 제작했다.

## 산출물

1. `MVP/development/mockups/Generated/council_heated_debate_concept_v1.png`
   - 상충하는 국경 보고를 두고 네 대신이 격론하는 핵심 회의
   - 폭우와 촛불, 발언 강조, 시선과 손동작으로 논쟁 상태를 표현
2. `MVP/development/mockups/Generated/council_early_two_advisors_concept_v1.png`
   - 두 대신만 참여하는 초반 소규모 회의
   - 미등장 인물의 빈 슬롯이나 물음표를 노출하지 않고 현재 인원만 자연스럽게 구성
3. `MVP/development/mockups/Generated/foreign_envoy_audience_concept_v1.png`
   - 여러 이웃 국가 중 하나의 사절단을 맞는 외교 알현
   - 동부를 처음부터 특별 취급하지 않고 복수 교류 방향과 관계 상태를 제시

공통 사항: 16:9, Codex built-in image generation, visual draft / non-canon / runtime 미연결.

## 우선순위 근거

- 격론 회의는 의견 종합과 왕의 선택이라는 핵심 플레이 루프를 가장 강하게 보여준다.
- 초반 2인 회의는 등장 조건과 회의 인원 확장 구조가 화면에서 자연스럽게 작동하는지 검증한다.
- 외국 사절 알현은 다중 왕국 관계 루트와 왕국 사건의 독립성을 동시에 검증한다.

## 공통 화면 원칙

- 왕은 화면에 등장하지 않고 왕좌 시점을 유지한다.
- 중앙 장면, 사건 자료, 왕국 상태, 연대기, 대신 의견, 왕의 선택이 한 화면에서 연결된다.
- 대신의 전신 또는 상반신에서 양팔·팔꿈치·손이 잘리지 않도록 구성한다.
- 연애 감정, 특정 장기 은유, 국가 문화의 확정, 과한 판타지 연출을 넣지 않는다.

## 검토 메모

- 생성 이미지 속 한글과 인물 이름·직함은 배치 예시이며 캐논 텍스트로 사용하지 않는다.
- 두 번째 시안의 이름·직함 배치에는 생성 모델의 혼선이 있으므로 UI 구조만 검토한다.
- 실제 구현 전에는 고정 캐스팅 이미지와 확정 대사를 사용해 재조립해야 한다.
- 세 장면을 비교해 좌우 패널의 상시 노출 여부, 상태 수치의 공개 수준, 발언 강조 방식부터 결정하는 것이 좋다.

## 변경 제외

Unity 런타임 코드, Ink, 스토리, `_shared`, `_history`, blind_test는 수정하지 않았다.
