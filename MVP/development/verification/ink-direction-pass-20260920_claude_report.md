## 2. 후반 대신 이름 변수화 (D9)
```ink
VAR name_watcher = "베이라"   // 가안
VAR name_chaplain = "오르반"  // 가안
VAR name_fool = "자벨"        // 사용자 확정명
```
영문 화자 6곳(`Watcher:`/`Chaplain:`/`Fool:`)을 `{name_*}:` 참조로 교체했다. 이름 확정 시 선언 3줄만 고치면 전체 반영된다.

## 3. 사실 상태 변수 신설 + 선택-상태 정합성 (D15 첫 적용)
```ink
VAR envoy_dispatched = true    // E18에서 사절단을 실제로 보냈는가
VAR king_abroad = false        // 왕이 지금 동부 땅에 있는가
VAR east_form = "open"         // 동부 관계 최종 형태: open | formal | bounded
```

**고친 모순 2건(Codex F01 지적)**
1. **E18 "파견 취소" → E20이 사절단 도착을 전제하던 문제.** 취소 시 `envoy_dispatched = false`를 남기고, E20 기본형이 이를 읽어 대체 서술("동부가 국경 통행 절차를 새로 공지한다. 우리 쪽에서 보낼 사람이 없으니…")을 출력한다.
2. **E20 "돌아간다" 후에도 왕이 동부에서 대면하던 문제.** 귀환 시 `king_abroad = false`. E22·E23 라우터를 `royal_visit && king_abroad`로 바꿔, 귀환하면 기본형(서신)으로 간다.

## 4. 동부 결말 3갈래 (D1)
E23의 응답 5종이 `east_form`을 남기고 E24·E25가 이를 읽는다.

| E23 선택 | east_form |
|---|---|
| 오해를 정리한다 / 미안했던 부분을 인정한다 | `open` |
| 현재 관계 형태를 확인한다 | `formal` |
| 더 요구하지 않는다 / 자신의 경계를 전달한다 | `bounded` |

**`세르안: 목표는 달성하지 못했습니다.`(무조건 출력) 제거.** 대신 형태별 서술 + `eastPressure` 기반 비용 서술로 교체했다. 사건 복제 없이 같은 knot 안 조건문으로 처리(승인 원칙 준수).
