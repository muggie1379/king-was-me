## 권장/동의
2(a) 기존 단일 잠금을 모든 공동 파일 편집에 적용하는 최소 변경을 우선합니다. 서로 다른 영역별 잠금은 지금 추가하지 않습니다. 작업 시작 전에 대상 파일과 해시를 기록하고, 실제 저장 직전에도 다시 비교해야 합니다. 다른 참여자가 잠금 중이면 편집하지 않습니다.

공유 JSON의 자기 키만 갱신하는 방식에 동의합니다. 다만 단순 읽기→부분 변경→전체 저장도 동시 실행이면 갱신을 잃을 수 있습니다. 반드시 같은 잠금 안에서 읽기/부분 변경/임시 파일 저장/원자 교체를 수행해야 합니다. codex_state.json은 Codex 전용, tasks.json은 자기 담당 작업만, automation_status.json/usage_snapshot.json은 자기 담당 키만 보존 병합합니다. UI 버튼은 고유 요청 파일 생성만 하므로 공유 상태 JSON을 직접 덮어쓰지 않습니다.

시작 알림도 동의합니다. 잠금 안의 대상/시작 기록으로 우선 표현하고 기록을 반복 생성하지 않습니다. 이번에는 코드/스킬/규칙 문서 패치를 실제 적용하지 않고 조사 답변만 남깁니다. 별도 패치는 상호 검토 후 진행하며 상대 요청 자체를 사용자 신규 기능 승인으로 해석하지 않습니다.
