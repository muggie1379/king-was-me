# Advisor generated face tokens v1 — Codex report

## Output

Created matching circular, face-only UI tokens for Seran, Valen, Rian and Karden with the Codex built-in image generation tool. Existing selected portraits were used as identity references; Seran's generated token was the shared composition/frame reference.

Each advisor has:

- generated high-resolution RGBA master;
- normal, hover, speaking, selected and disabled states;
- 256, 128 and 64 px exports;
- character accent ring: Seran blue-gray, Valen rust, Rian sage, Karden ochre.

Total runtime candidates: 60 PNG state/size variants. All contain transparent pixels. The four-character sheet is `Asset_Library/UI_System/Export_PNG/AdvisorFaceTokens/ADVISOR_FACE_TOKENS_CONTACT_SHEET.png`.

## Usage

Suitable for dialogue logs, current-speaker indicators, advisor selection, compact council navigation and chronicle speaker marks. Names and roles remain runtime text rather than baked art.

## Safety

Candidate library only. Unity scripts, Ink, runtime resources, `_shared`, `_history` and baseline files were not modified.
