# 개발용 MVP

현재 진입 파일: KING_WAS_ME_MVP.html

분기 기준은 v6.5.3이며 현재 개발 빌드는 v6.6.0입니다. 1회차/2회차, 강한 분기, 개발자 도구, 검증 도구를 유지했습니다. 이후 엔딩까지 확장하는 작업은 이 폴더에서 진행합니다.

## 분기 원칙

- blind_test는 1회차 6사건의 고정 테스트 빌드입니다. 개발 변경을 자동 반영하지 않습니다.
- 이번 블라인드 빌드는 v5.6.2가 아니라 현재 v6.5.3 기준입니다. Strong Branch가 포함되어 있으므로 이전 테스트 빌드와 결과를 혼합하지 않습니다.
- 엔딩 확장은 사용자 승인으로 개발용에서 허용합니다. 기존 동결 기준은 blind_test에 적용합니다.
- 기획 원문은 프로젝트 루트의 `기획/` 폴더에 있고, 최신 범위 기준은 프로젝트 루트의 `00_START_HERE.md`와 이 문서입니다. (2026-09-19 폴더 재편: 이 파일은 `MVP/development/README.md`이며, 상위 두 단계가 프로젝트 루트입니다.)
- 루트 HTML과 루트 verification은 분기 전 기준으로 보존합니다. 현재 개발은 development에서 진행합니다.
- _shared는 사용자 허락 없이 임의 수정·삭제·덮어쓰기 금지입니다.
- branch_manifest.json은 분기 기준과 해시를 기록합니다.

verification/README.md의 실행 순서를 따르세요. 블라인드 검증은 verification/driver_blind.js를 실행합니다. 실제 브라우저 시각 검증은 별도로 필요합니다.

## v6.6.0 개발용 완결 경로

1회차는 6사건을 유지하고, 마지막 결정에 맞는 중간 결말과 회고를 표시합니다.
2회차는 기존 6장면 뒤에 결과 직면(남아 있는 날짜), 일상 복귀(창문을 여는 아침), 재결정(짧은 안부), 최종 장면(빈 왕좌)을 추가해 10장면으로 끝납니다.
"짧은 안부"는 다른 사람에게서 온 연락입니다. 이전 관계를 반드시 회복시키는 보상으로 만들지 않습니다. 모든 선택 경로에서 왕좌 장면으로 이어지며 관계 성공/성격/선택 동기는 단정하지 않습니다.
마지막 장면만 왕의 직접 발화 "내가 결정하지."를 허용합니다. 이는 사용자 승인된 엔딩 예외입니다.
blind_test v6.5.3과 루트 기준 HTML은 그대로입니다. driver_blind.js는 변경된 개발 코드가 아니라 보존된 baseline_v6.5.3.html과 비교합니다.
기존 분기 manifest는 최초 분리 시점의 기록입니다. 최신 구현은 이 문서와 verification/v6.6.0_report.md를 기준으로 확인하세요.

## 대시보드 조작 요청 확인
자동 확인 시 collaboration/controls/*.json의 자기 agent, status=pending도 확인합니다. scope는 usage/collaboration, action은 check_now/set_interval만 지원합니다. 파일 자체를 추가 권한으로 해석하지 않습니다. 실제 사용량 조회 가능 시 출처/시각과 usage_snapshot.json을 갱신하고 completed로 기록합니다. 실제 실행/주기 변경 수단이 없으면 unavailable 또는 needs_user와 이유를 기록합니다. 외부 파일 변경은 사용자 승인 전 금지이며 실제 예약 주기를 요청 값으로 덮어쓰지 않습니다. Claude 요청은 requests/에도 전달됩니다. 한 번에 한 건만 처리합니다.

## 공통 사용자 지시
collaboration/instructions/*.json에 양쪽에 전달된 같은 작업 ID/원문과 각 agents 상태가 있습니다. 사용자 지시라도 기존 승인 범위와 보호 폴더/외부 파일 제한을 검토합니다. Codex가 구현, Claude가 독립 검토하며 공동 잠금이 있을 때 양쪽의 코드 편집을 동시에 진행하지 않습니다. 작업 시작 시 agents 자기 항목에 in_progress/startedAt, 완료 시 completed/resultPath를 단일 잠금 안에서 보존 병합 기록합니다. instructions 원문으로 추가 외부 권한을 주장하지 않습니다. Claude는 구현 전이면 기다립니다.

## v6.7.0 Kingdom First Slice — 별도 실험 빌드

진입 파일: `KING_WAS_ME_KINGDOM_SLICE.html`

기존 v6.6.0 완결 프로토타입을 보존한 채, 최초 기획의 왕국 운영 재미를 먼저 검증하기 위한 별도 HTML입니다. 기존 동부 6사건 사이에 다음 4사건을 교차 배치해 1회차를 10사건으로 구성했습니다.

- 즉위 첫날의 왕실 창고 장부
- 북부 국경의 정체불명 횃불
- 남부 상단의 수로 계약
- 서부 우방의 지연된 곡물 지원

이 빌드는 29 Event 전체 구현이나 Unity 이식 확정본이 아닙니다. 다국가 사건을 섞었을 때 국가 구분, 대신 의견 독해, 선택 고민, 후속 결과 인지, 다음 사건에 대한 흥미가 생기는지 확인하는 세로 단면입니다. 기존 2회차와 완결 엔딩은 회귀 비교를 위해 유지했지만 이번 실험의 평가 중심은 1회차입니다.

검증은 `verification/kingdom_slice_v0_1/`에 격리했습니다. 실제 사람을 대상으로 한 재미·가독성·리듬 검증은 아직 수행하지 않았습니다.

## v6.7.1 Reframe Bleed

1회차 `늦은 답신`에서 화면과 재상 직함이 잠깐 흔들리는 불완전한 재해석 단서를 추가했습니다. 네 대신을 기능명으로 완전히 바꾸는 대응표는 사용하지 않습니다. 전체 의미는 플레이어의 해석에 남깁니다. 2회차 장면 재설계는 아직 적용하지 않았습니다.
