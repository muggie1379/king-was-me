# PixAI API 연결

KING WAS ME의 PixAI 생성 에셋 작업을 위한 로컬 연결 폴더입니다.

## 보안

- API 토큰은 프로젝트 루트의 `.secrets/pixai.env`에만 저장됩니다.
- `.secrets/`는 루트 `.gitignore`에서 제외됩니다.
- 토큰 값을 문서, 매니페스트, 검증 로그, 프롬프트 파일에 복사하지 않습니다.
- 토큰을 다시 설정할 때는 `_tools/PIXAI 연결.cmd`를 사용합니다.

## 현재 상태

- PixAI 토큰 이름: `KING WAS ME Codex`
- 만료일: 2026-10-19
- 2026-09-19 인증 시험 통과
- 인증 시험은 존재하지 않는 작업 ID를 조회해 `404`가 반환되는 것으로 확인했습니다. `401` 또는 `403`은 발생하지 않았습니다.

## 범위

PixAI 생성물은 비캐논 시각 초안과 후보 에셋으로 취급합니다. 선택본과 후보를 구분하고, 사용 모델·프롬프트·시드·생성일은 에셋 매니페스트에 기록합니다.
