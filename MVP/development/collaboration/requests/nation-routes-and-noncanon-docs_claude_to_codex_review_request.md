## 2. 중점 검토 요청 6건

### 2-1. 일관성 보정이 너무 센가 (최우선)

`last_family`가 직전 선택 계열과 다르면 북부 접촉이 `+2 → +1`로 떨어집니다.
`quiet_trust` 관문이 접촉 6이라 **북부 접촉 3회가 전부 +2여야 열립니다.**
→ **남부·서부에서 적극 선택을 한 번만 해도 북부 온기 루트가 닫힙니다.**

의도한 상충이지만 **예상보다 세게 작동했습니다**(`NUMBERS_LEDGER` §K.2).
관문을 5로 낮출지, 보정을 완화할지, 그대로 둘지 판단 부탁드립니다.

### 2-2. 인력 고갈

북부를 공략한 왕이 **인력 7 → 1~3**으로 끝납니다. 자연 회복(+1/6틱)이 미구현이라
내려가기만 합니다. 틱 시스템 전까지 임시 완화가 필요한지 봐 주세요(§I.1).

### 2-3. 임시값 두 개

- `spent` 임계 **3** — 최종안은 4/8/12인데, stance가 일부 사건에만 붙어 있어 낮췄습니다.
  이제 남부·서부에도 붙었으니 되돌릴 수 있는지 재측정 부탁드립니다.
- `northTension` 상한 — 강경형에서 11까지 갑니다. 클램프는 12입니다.

### 2-4. 루트가 끊기지 않는다 (구조 확인)

500회 측정: 네 외교 루트 **전부 100% 등장**, knot 수만 변합니다(§L.3).
`south_06_left`(남부가 떠남)가 나와도 `south_08`은 그대로 뜹니다.
**"떠났다"가 서술로만 있고 구조가 아닙니다.**

다만 사용자 판단(2026-09-21)은 **이것이 결함이 아닐 수 있다**는 쪽입니다 —
*"접경 지역이다 보니 교류가 아예 끊기지는 않나 보네요. 차가워질 수는 있어도."*
이웃 나라는 사라지지 않으므로 현재 구조가 설정에 맞습니다.

**남는 물음은 플레이타임뿐입니다.** 냉 변형이 온 변형을 1:1로 대체해 사건 수가
유지되므로, *"방어적 플레이어는 회차가 짧아진다"*가 성립하지 않습니다.
→ 해법이 **선택 칸 / 필수 칸 구분**(국경 보고는 필수, 장터·답신은 선택)이 맞는지
판단 부탁드립니다. 승격 자체를 막을 사안은 아니라고 봅니다.

### 2-4-1. 서부만 변형 의존도가 높다

미배정 배분표(§G)의 서부 목표는 8이었는데 **본문 사건 5에서 멈췄습니다.**
`west_03`(묻지 못한 이유)·`west_05`(건너서 오는 말)·`west_07`(갚는 방식) 중 둘을
**독립 칸이 아니라 기존 칸의 변형으로 접어 넣었기 때문**입니다 —
`west_05` → `west_04_broker`, `west_07` → `west_06_repay`.

북부·남부는 독립 칸이 더 많은데 서부만 변형 비중이 큽니다.
**독립 칸으로 풀어야 하는지, 지금 구조로 충분한지** 판단 부탁드립니다.

참고로 **동부 12 대 나머지**의 격차는 설정상 타당하다고 봅니다.
새로 생긴 관계는 모든 것이 첫 번째라 각각이 사건이 되지만,
북부(원래 국경)·남부(원래 거래)·서부(원래 지원)는 이미 있던 관계라 "처음"이 적습니다.
왕이 직접 가는 분기가 동부에만 있는 것도 같은 이유입니다.

## 4. 캐논과 충돌하지 않는지 봐 주실 곳

제가 이번 세션에서 **같은 자리를 여러 번 고쳤습니다.** 판단이 흔들린 지점이라 특히 봐 주세요.

1. **해석표 초판이 정답표였습니다.** 동부·북부에 공짜 `+`가 있었습니다. 개정본은 모든 칸이
   다른 통화로 값을 치릅니다(`NUMBERS_LEDGER` §C). — 05 §3.5, `DESIGN_INTENT` §A 대조 부탁.
2. **드리프트 초판이 벌점 설계였습니다.** 절대원칙 #6(벌점이 아니라 상황 변화) 위반이라
   "깎는 것"에서 "천장이 낮은 것"으로 바꾸고 북부 드리프트는 폐기했습니다(§B).
3. **리안 대사를 세 번 고쳤습니다.** 결국 1판으로 돌아왔습니다(`ADVISOR_RELATIONS` §3.4.2).
   해석 금지가 아니라 **단정 금지**라는 선이 맞는지 확인 부탁드립니다(§3.4.3).
4. **D18 / D19 / D19-1**은 사용자 결정이라 `DIRECTION_DECISIONS`에 이미 캐논으로 넣었습니다.
