## 0. 세 층

| 층 | 무엇 | 변수 |
|---|---|---|
| **1. 선택 이력** | 무엇을 실제로 했는가 | stance 히스토리, 7축, `spent` |

## 1. 표시 경계 — 이 설계에서 제일 중요한 규칙

D15가 이미 정한 선이다. **자원 4종이 같은 취급이 아니다.**

| | 서재 장부에 숫자로 | 근거 |
|---|---|---|
| `treasury` 국고 | **보인다** | 통장은 확인할 수 있다 |
| `grain` 곡물 | **보인다** | 창고 재고는 세면 된다 |
| `labor` 인력 | **보인다** | 사람 수는 세면 된다 |
| `morale` 민심 | **안 보인다** | 사람 마음이다. §12.1 |

> D15 원문 표: *보여도 되는 것 — 국고, 곡물 재고, 병력 수, 밀린 일정 /
> 보이면 안 되는 것 — **민심**, 호감도, 관계 온도, 7축*

**`morale`은 내부 변수로만 존재한다.** 플레이어는 숫자를 절대 못 본다.
대신 **체납 · 주민 이탈 · 짧아진 보고 · 대신의 말투**로만 알아챈다.
`국고 72 / 민심 48` 같은 경영 게임 표시는 하지 않는다.

**표시 위치:** 서재 화면의 "국정 현황" 카드. `TempScreens.ShowStudy`에 자리는 있으나 지금은 빈 껍데기다.
HUD 상시 표시가 아니다 — **확인하러 가는 행동 자체**가 "지금 내 형편을 본다"가 된다.

**개발자 화면:** 4종 전부 정확한 값을 본다. 에디터 전용 오버레이로 분리한다.

## 2. 자원 4종

범위를 **전부 0~12로 통일**한다. 추적 가능성이 우선이고, 성격 차이는 범위가 아니라
**회복 속도**와 **바닥 효과**로 만든다.

| 자원 | 시작 | 자연 회복 | 바닥(0~2)에서 벌어지는 일 |
|---|---|---|---|
| `treasury` 국고 | 8 | +1 / 4틱 | 외교 행동 자체가 막힌다(`home_levy` 강제) |
| `grain` 곡물 | 8 | 없음 — 수확·수입만 | 배급 사건, `labor` 추가 감소 |
| `labor` 인력 | 7 | +1 / 6틱 | 사절 파견·대규모 행동 선택지가 사라진다 |
| `morale` 민심 | 7 | +1 / 8틱 | 체납·이탈. **회복이 가장 느리다** |

**밴드** — 서술과 조건은 정확한 값이 아니라 이 구간을 읽는다.

```
0-2 위태    3-5 부족    6-8 보통    9-12 여유
```

## 3. 증감 규칙

외교 선택이 남기는 물질적 결과. **표에 없는 행동은 자원을 건드리지 않는다.**

| 행동 | 국고 | 곡물 | 인력 | 민심 |
|---|---|---|---|---|
| 사절 파견 | −2 | | −1 | |
| 왕의 직접 방문 | −3 | | −1 | −1 |
| 공물 · 선물 | −2 | | | |
| 타국 의전 참석 | −2 | | | |
| 남부 대형 계약 수락 | −1 | | −2 | |
| 남부 선불 요구 수락 | −3 | | | |
| 서부 지원 유지(불리한 조건) | −1 | **+3** | | |
| 서부 지원 상실 | | **−3** | | |
| 북부 접촉 1회(서신·장터 묵인) | | | −1 | |
| **세금 인상** (D16) | **+4** | | | **−2** |
| **징발** | +2 | | −2 | −1 |
| 수확기 (ACT 경계) | | +2 | | |
| 해안 축제 참여 | −1 | | | **+1** |

**D16의 뜻이 세금 줄에 들어 있다.** 국고를 채우는 길은 민심을 쓰는 것뿐이다.
*"체력을 더 써서 감정을 더 쏟게 된다"* — 강요가 아니라 왕이 고르는 것이다.

**해안이 민심을 올리는 유일한 외교다.** 부담 없는 관계가 실제로 회복을 준다.

## 4. 내정 사건 발생 조건

| 사건 | 조건 | 회복 경로 |
|---|---|---|
| `home_ration` 겨울 배급 | `grain <= 5` | 서부 지원 재개, 수확 |
| `home_tax` 세금 | `treasury <= 4` | — (이것이 회복 수단) |
| `home_arrears` 체납 | 세금 인상 후 && `morale <= 4` | 시간 |
| `home_leave` 떠나는 사람들 | `morale <= 3` | `home_return` |
| `home_levy` 징발 | `treasury <= 3` && 외교 행동 필요 | — |
| `home_illness` 앓는 계절 | `labor <= 5`일 때 확률 가중 | 시간 |
| `home_backlog` 밀린 안건 | **`spent` 임계 4 / 8 / 12** | 처리(시간 소모) |
| `home_return` 돌아온 사람들 | `home_leave` 이후 && `morale >= 6` | — (이것이 회복) |

**하강 일변도를 막는 장치가 셋이다.** `home_return`, 해안 축제, 수확기.
전부 내려가기만 하면 플레이어는 손을 놓는다.

### 4.1 과속 방지

4자원 × 8사건은 방치하면 서사를 덮는 경영 게임이 된다. 두 가지로 막는다.

1. 내정 사건은 자원이 **밴드를 넘어서는 그 순간에만** 뜬다. 같은 밴드에 머무는 동안 반복되지 않는다.
2. **한 ACT에 내정 사건 최대 2건.**

## 5. 엔딩에서의 쓰임

엔딩을 **가르지 않는다.** 엔딩은 `*_form` 4개가 가른다(`NATION_AXES` §3).
자원은 **같은 엔딩의 서술 배경**만 바꾼다.

> 동부와 `open`으로 끝난 왕국이 국고 `위태`이면 — 오가는 길은 남았는데 보낼 것이 없다.
> 같은 `open`인데 `여유`이면 — 다음 사절 일정이 이미 잡혀 있다.

**관계에서 좋은 선택이 왕국에도 좋은 선택은 아니다.** 이 설계의 목적이 그것이다.
