# 회의 화면 레이아웃 목업 v1 — Codex, 2026-09-19

## 목적

좌석 포즈를 더 만들기 전에 실제 16:9 게임 화면에서 캐릭터가 차지할 영역과 UI 안전 영역을 검증한다.

## 산출물

- `MVP/development/mockups/COUNCIL_SCREEN_LAYOUT_V1.html`
- 회의 진행 / 의견 종합 화면 전환 가능
- 기존 회의실 배경, 확정 캐릭터 초상 방향, 기존 UI 패널의 색·재질을 참조

## 레이아웃 기준

- 상단: 사건 제목과 사건 진행도
- 중앙: 소개된 대신 4명의 가변 좌석 영역
- 하단 약 24%: 대화 패널 또는 선택지
- 의견 종합: 2×2 카드와 왕의 선택 버튼
- 왕은 화면에 표시하지 않고 카메라 위치로만 존재

## 발견

기존 세르안 좌석 포즈 6종은 양쪽 소매와 팔꿈치가 화면 경계에 너무 가까워 좌석 합성과 몸 돌림에 부적합하다. 모두 `Candidates/Seran/Cropped_v1/`으로 내렸다. 양팔·팔꿈치·손·의자 폭 전체를 포함한 wide-frame idle 후보를 새로 만들었으며, 화면 목업 승인 후 동일 프레이밍으로 포즈 세트를 다시 생성해야 한다.

## 변경 제외

`Assets/Scripts`, `Assets/Resources/Ink`, 스토리 파일, `_shared`, `_history`, blind_test는 수정하지 않았다.
