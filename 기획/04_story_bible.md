# 0. 문서 목적

이 문서는 《KING WAS ME》의 풀게임 스토리 구조를 정리한 스토리 바이블이다.

> **2026-09-19 승인 보강:** 동부만 관계 지속의 대상이 아니다. 모든 주변국은 실제 결정에 따라 고유한 다음 장면을 가질 수 있고 여러 관계가 동시에 열릴 수 있다. 국가와 현실 관계의 1:1 대응은 확정하지 않는다. 상세 기준은 05_multi_kingdom_relationship_routes.md가 과거 미정 항목보다 우선한다.

2026-09-18 블라인드 플레이테스트에서 다음 피드백이 나왔다.

> "선택하다 보니 연애하듯 선택하고 있었다." / "왕에게 자신을 이입하게 되었다." / "상대가 교류를 끊자 오히려 이어가고 싶어졌다."

뒤의 두 반응은 설계가 의도대로 작동했다는 긍정 신호다 — 게임이 설명해서가 아니라 플레이어가 스스로 자기 욕구를 발견했다. 이 경험은 반드시 지킨다.

문제는 "동부 왕국 = 썸 상대"라는 공식이 너무 빨리 완성된다는 점이었다. 원인은 개별 사건이 아니라 **사건 배열 자체**였다 — 관계 코드가 붙은 사건들이 전부 동부 하나와만, 연속으로 발생했기 때문이다.

이번 개정은 이를 해결하기 위해 **5개국 교차 배치**로 22 Event를 재설계한다.

최우선 원칙:

- 왕 = Self / 플레이어
- 왕은 궁정 회의 참가자가 아니다.
- 플레이어 선택은 왕의 대사가 아니라 행동/결정이다.
- 왕은 가능하면 마지막까지 직접 말하지 않는다.
- 상대의 속마음은 확정하지 않는다.
- 관찰 가능한 사실과 해석을 분리한다.
- 핵심 4인: 세르안 / 발렌 / 리안 / 카르덴
- **강한 선택 → 강한 분기**
- 2회차는 해설편이 아니라 재해석이다.
- 현실은 보여주되 해석은 보여주지 않는다.
- 엔딩은 `KING WAS YOU → 뭐해? → 빈 왕좌 → 최초 왕 1인칭 → 내가 결정하지. → KING WAS ME`.

## 0-1. 신규 Do Not Drift — 다국가 구조 3원칙

> ### WORLD-FIRST METAPHOR RULE
> 모든 왕국 사건은 인간관계 은유를 제거해도 독립적인 왕국 사건으로 성립해야 한다. 현실 경험과의 대응은 두 번째 해석이어야 한다.

> ### EASTERN KINGDOM RULE
> 동부 왕국은 게임이 처음부터 특별하게 만드는 국가가 아니다. 반복되는 사건과 플레이어의 관심이 결과적으로 특별하게 만든다. 첫 등장부터 전용 BGM·따뜻한 색감·특별한 카메라를 쓰지 않는다.

> ### WORLD CONTINUES RULE
> 플레이어가 한 관계(동부)에 집중하는 동안에도 세계의 다른 관계와 사건은 계속 움직인다. "동부 문제로 회의 11번, 다른 일은 첫 회의도 못 함" 같은 장면으로 **보여준다**, 설명하지 않는다.

# 1. 전체 5막 구조

## ACT I — 작은 왕국
**주제:** 판단하는 법을 배운다.

플레이어는 작은 왕국의 통치 시스템을 익힌다. 아직 외국은 등장하지 않거나 아주 약한 신호만 있다.

감정 곡선:
> 안정 → 가벼운 불확실성 → 첫 행동

핵심 인물:
- 세르안 · 재상 / 판단
- 발렌 · 원수 / 행동

---

## ACT II — 여러 이웃, 그중 하나의 사절
**주제:** 관계가 생기면 판단은 더 어려워진다. 동시에 왕국에는 이웃이 여럿이다.

동부 왕국과의 접촉이 반복되는 관계로 발전하는 동안, 남부·북부·서부의 사건도 교차로 진행된다. **동부는 처음엔 "여러 이웃 중 하나"로만 보여야 한다(EASTERN KINGDOM RULE).**

감정 곡선:
> 호기심 → 기대 → 즐거움 → 의미 부여 (동부) + 국정 업무의 다양성 (타국)

핵심 추가 인물:
- 리안 · 외교관 / 관계

---

## ACT III — 흔들리는 국경
**주제:** 정보가 줄어들수록 내면의 목소리는 커진다. 그래도 세계는 멈추지 않는다.

동부의 답신 지연·회담 취소·침묵이 겹치며 문제는 동부의 의미뿐 아니라 **우리 왕국의 소모**가 된다. 같은 시기 해안·남부·북부에서도 각자의 사건이 진행된다(WORLD CONTINUES RULE).

감정 곡선:
> 기다림 → 불확실성 → 해석 증가 → 내부 소모

핵심 추가 인물:
- 카르덴 · 수호관 / 경계

---

## ACT IV — 필요 없었던 전쟁
**주제:** 불확실성을 없애려는 행동이 압박이 될 수 있다. 그리고 다른 나라의 일도 밀려 있다.

"전쟁"은 반드시 군사전쟁을 뜻하지 않는다 — 관계를 확정하려는 시도가 임계점을 넘는 순간을 외교·군사 언어로 표현할 수 있다. 동시에 카르덴은 동부에 쏠린 시간·자원 때문에 다른 나라 일이 밀리고 있음을 사실로 보고한다.

감정 곡선:
> 해결 욕구 → 압박 → 경계 → 수용

---

## ACT V — 나라를 지키는 법
**주제:** 하나의 관계는 세계 전체가 아니다.

동부 문제의 결과와 별개로, 서부와의 회담이 다시 열리고 남부 상단이 돌아오고 북부 경계가 안정되고 해안 축제가 다시 보인다 — **설명이 아니라 지도를 보여주는 것만으로** 세계가 원래 넓었다는 걸 체감시킨다.

감정 곡선:
> 복구 → 재배치 → 다시 열림 → 자기 통합

# 2. 세계관 — 주변국 개관

국가명은 가안이며 최종 세계관 설계 과정에서 변경할 수 있다.

## 2.1 동부 왕국
**관계 성격:** 새롭게 형성되어 점점 중요도가 높아지는 관계.
**주요 테마:** 호의 / 상호성 / 기대 / 불확실성 / 거리 / 경계
**주의:** 처음부터 특별한 관계로 연출하지 않는다.

## 2.2 서부 연합
**관계 성격:** 오래된 우방. 신뢰의 기반이 이미 존재한다.
**사용 가능한 사건:** 오래된 약속이 지켜지지 않음 / 예전엔 당연했던 지원이 줄어듦 / 연락이 뜸해졌지만 적대는 아님 / 서로 너무 익숙해서 생기는 무심함
**인간관계 해석 가능성:** 오래된 친구·지인·관계. 게임에서는 확정하지 않는다.

## 2.3 남부 상업국
**관계 성격:** 이해관계와 계약 중심.
**주요 사건:** 무역 조건 변경 / 계약 해석 차이 / 손해를 감수한 협력 / 협상 / 상대가 더 유리한 조건을 요구
**장점:** 세르안·리안·카르덴을 진짜 국정 인물로 보이게 한다. 리안이 동부에서만 "거리와 온도"를 말하면 관계 상담가처럼 보이지만, 남부 협상에서 "이번엔 상대가 먼저 조건을 바꿨습니다. 우리가 다시 양보할 차례는 아닙니다"라고 말하면 실제 외교관처럼 느껴진다.

## 2.4 북부 변경국
**관계 성격:** 경계와 안보 문제가 많은 국가.
**주요 사건:** 국경 병력 이동 / 오인 가능성이 있는 군사 활동 / 국경 통행 문제 / 방어 병력 증강 / 정보 부족 속 대응
**주요 캐릭터:** 발렌과 세르안을 가장 자연스럽게 보여준다. 발렌이 북부에서도 행동을 제안해야 "동부에서만 밀어붙이는 인물"이 아니라 "원래 모든 상황에서 행동을 담당하는 사람"으로 읽힌다.

## 2.5 해안 도시국가
**관계 성격:** 가볍고 유동적인 교류.
**주요 사건:** 문화 행사 / 축제 / 짧은 협력 / 소문과 정보 / 갑작스러운 방문
**역할:** 스토리에 밝은 호흡과 세계의 넓이를 제공한다.

# 3. 생활 NPC

블라인드 테스터 피드백: "캐릭터가 현실감이 없다" → "캐릭터가 많이 없다".

해결책은 **핵심 4인(세르안/발렌/리안/카르덴)을 늘리는 것이 아니다.** 이 네 명의 심리 기능은 오히려 지금처럼 선명하게 유지한다. 필요한 건 **왕국에 사는 평범한 사람들**이다.

**로스터(후보):** 문지기 / 서기관 / 국경 경비대장 / 상인 / 사절 / 시종 / 농민 대표 / 항구 관리관 / 재무 담당자 / 타국 외교관 / 상단 대표 / 병사

이들은 심리 기능이 아니다. 그냥 이 세계를 살아가는 사람들이다.

**역할:**
1. **사건 전달** — 항상 세르안이 보고서를 읽지 않는다. 문지기가 뛰어 들어오거나, 국경대장이 직접 보고하거나, 상인이 항의하러 올 수 있다.
2. **이전 선택에 대한 반응** — "폐하께서 지난번 통행세를 낮추신 뒤 상인들이 다시 들어오기 시작했습니다." 플레이어 선택이 세계에 남는다는 느낌을 강화한다.
3. **궁정의 생활감** — 대신들이 항상 왕만 바라보지 않는다. 서류를 정리하고, 다른 인물과 이야기하고, 농담하고, 짜증 내고, 기다린다.
4. **대신 캐릭터의 현실화** — 세르안이 서기관을 대하는 모습, 발렌이 병사와 이야기하는 모습, 리안이 외국 사절과 협상하는 모습, 카르덴이 창고나 일정표를 확인하는 모습.

각 Event의 상세 항목에 "생활 NPC" 필드를 추가했다(해당하는 경우).

## 3.1 생활 NPC의 은유 — 사용자 확정

왕실 대신을 제외한 인물은 인간의 장기처럼, 판단과 감정을 대신 결정하지 않으면서 전체를 유지하는 각자의 일을 한다. 은유는 인물의 업무와 세계의 반응에서 느껴지게 하며 특정 인물=특정 장기의 고정 대응표를 만들지 않는다. 서기관=뇌, 상인=위장처럼 과한 매칭이나 게임 안 해설은 사용하지 않는다.

이들은 왕국의 결정·감정을 담당하는 렌즈가 아니다. 재고·물자·통행·정보 전달·현장 업무의 사실, 업무상 요청과 결과를 보고한다. 생활인의 감정이나 이해관계는 가질 수 있지만 왕의 감정을 판정하거나 정책 결론을 대신 내리지 않는다. 업무 관점의 설명은 대신 의견 카드와 분리한다. 후반 왕실 대신 후보(Watcher/Chaplain/Fool 등)는 생활 NPC로 재분류하지 않는다.

# 4. 개발자 전용 은유 대응표

이 표는 **게임 내 정답표가 아니다.** 앞으로는 "현실 대응 가능성 / 정서적 대응"으로 표현한다 — 개발자조차 1:1 대응에 과도하게 의존하지 않아야 결과물에서도 은유가 자연스럽게 유지된다.

| 왕국 표면 | 현실 대응 가능성 |
|---|---|
| 사절 | 연락 / 메시지 / 접근 |
| 답신 | 답장 / 반응 |
| 공동 행사 | 함께 보낸 시간 / 만남 / 친구와의 만남 / 데이트 (여러 가능성 중 하나) |
| 회담 | 직접 대화 / 약속 |
| 공물 | 선물 / 편지 / 감정적 투자 |
| 국경 | 관계의 경계 |
| 조약 | 합의된 관계 형태 |
| 병력/사절단 증강 | 강한 확인 / 압박 / 확답 요구 |
| 철수 | 한발 물러남 / 적극 행동 중단 |
| 왕국 내부 자원 | 시간 / 집중 / 감정 에너지 / 일상 |
| 전후 복구 | 자기 삶의 회복 |
| 무역 조건 재협상 (남부) | 계약·업무 협상 / 관계의 조건 재조정 |
| 오래된 지원 축소 (서부) | 오래된 관계에서 느끼는 무심함 |
| 국경 병력 이동 (북부) | 반복되는 애매한 신호에 대한 대응 |
| 가벼운 축제 초대 (해안) | 부담 없는 모임·지인 교류 |

**중요:** 동부 왕국 = 특정 연애 상대라고 Canon으로 고정하지 않는다. 다른 국가들도 마찬가지다.

# 5. 스토리 공통 규칙

## 왕의 침묵

기본 흐름:
> 외부 사건 → 대신들의 해석/논쟁 → 플레이어 행동 선택 → 외부 결과

왕은 대신과 토론하지 않는다. 내레이터도 "왕은 불안했다" 같이 플레이어의 내면을 확정하지 않는다.

## 정보 규칙

게임이 보여주는 것: 실제 행동 / 실제 말 / 실제 시간 / 실제 약속 / 실제 경계
게임이 확정하지 않는 것: 왜 그랬는가 / 진짜 마음이 무엇인가 / 사랑했는가 / 싫어했는가 / 기다리는가 / 일부러 밀어내는가

## 분기 규칙

**History First, Stats Second** — 직전 선택과 실제 이력이 우선한다.

## 5.1.7 도달 가능 범위와 발생 이력

현재 Ink 증감 기준: northTension 시작 2, E03 최대 +1, E07 최대 +2로 E21 직전 최대 5다. 따라서 E21은 `northTension >= 5 and north_hardline`으로 판정한다. E03 정찰/수비 + E07 수비 경로는 발생하고, E03 관찰 + E07 수비(4) 또는 외교 확인 경로는 스킵된다. E16에는 임의 증감을 추가하지 않는다.

E21 실제 진입 시 `north_incident_occurred = true`를 기록한다. E26은 현재 긴장도를 다시 검사하지 않고 이 이력으로 회수한다. E21에서 자제를 선택해 수치가 내려가도 이미 발생한 사건을 없던 일로 서술하지 않는다.

# Event 01. 즉위 [내정]

## 표면 사건
플레이어가 작은 왕국의 왕으로 즉위한다. 왕국은 화려한 제국이 아니다. 첫날 올라오는 것은 거대한 전쟁이 아니라 사소한 행정 문제다.

## 드라마 목적

## 핵심 질문
> **정보가 완전하지 않아도 결정을 내려야 한다면 무엇을 기준으로 할 것인가?**

## 관찰 가능한 사실
- 창고 장부와 실제 재고가 조금 다르다.
- 담당자는 기록 실수 가능성을 말한다.
- 당장 큰 피해는 없다.

## 대신
세르안: "기록부터 맞춰야 합니다."
발렌: "오늘 처리하면 내일 다시 안 봐도 됩니다."

## 생활 NPC
창고 담당 서기관 — 재고 오차를 직접 보고.

## 선택 예
- 기록을 다시 확인한다.
- 담당자를 불러 즉시 정리한다.
- 작은 오차로 보고 현 상태를 유지한다.

## 분기
튜토리얼성 경미한 차이만 발생.

## 현실 대응 가능성
일상적인 작은 의사결정. 아직 인간관계 은유를 거의 드러내지 않는다.

## 금지
선택을 근거로 "신중한 왕", "충동적인 왕" 같은 성격 판정 금지.

## Unity 연출
- 왕의 얼굴은 보여주지 않음
- 왕좌의 실루엣 / 손 / 옷자락
- 대신들이 왕을 보고 말함
- 왕은 대답하지 않고 플레이어가 행동 선택

# Event 14. 손해 보는 협상 [남부] — 신규

## 드라마 목적
관계 유지에는 때로 손해가 따른다는 것 — 그리고 그 기회조차 이전 선택으로 사라질 수 있다는 것.

## 핵심 질문
> **상대가 유리한 조건을 요구할 때, 관계를 위해 손해를 감수할 것인가?** (결렬 변형: **되돌릴 수 없는 것과 아직 할 수 있는 것을 구분할 수 있는가?**)

## 관찰 가능한 사실 — 기본형
- 남부가 새 조건을 제시
- 수용 시 손해 발생
- 거절 시 관계 냉각 가능

## 관찰 가능한 사실 — 결렬 변형
- 남부가 협상 테이블 자체를 접음
- 추가 조건 제시 없음
- 대안 무역로 이용 시작 정황

## 대신 — 기본형
카르덴: "이번엔 우리가 손해를 좀 봐야 관계가 유지됩니다."
세르안: "감정과 계산은 분리해야 합니다."

## 대신 — 결렬 변형
카르덴: "이번엔 손해를 볼 기회조차 없습니다."
리안: "지난번 선택의 대가입니다. 지금 할 수 있는 건 다음을 준비하는 것뿐입니다."

## 선택 — 기본형
- 손해를 감수하고 수용한다. → **`south_sacrifice = true`**
- 절충안을 재요청한다.
- 거절하고 관계 냉각을 감수한다.
- 시간을 벌며 재검토한다.

## 선택 — 결렬 변형
- 대안 무역로를 알아본다.
- 남부에 재협상을 공식 요청한다(수락 여부는 확정하지 않음).
- 그대로 받아들인다.

## 분기
기본형: 남부와의 향후 관계 형태 결정, `south_sacrifice` 설정 시 E19 톤이 완화됨. 결렬 변형: 선택과 무관하게 **E19가 스킵**되고 "§5.1.5 끊어진 상단" 브리지로 대체(남부 스레드 종료).

## 현실 대응 가능성
관계 유지를 위한 양보와 손해.

## 금지
손해 감수를 "옳은 선택"으로 규정하지 않는다 — 거절도 옳을 수 있다.

## Unity 연출
협상 탁자, 서류 위 숫자 클로즈업.

## 현실 대응 가능성
주변 조언 / 머릿속 가설 증식.

## Unity 연출
같은 사실이 여러 문서에서 다른 강조로 보임.

# Event 17. 왕실 회의 [종합]

> 동부 문제가 여전히 중심이지만, 다른 나라 사안도 함께 보고되는 종합 회의로 확장.

## 드라마 목적
게임의 "내적 회의" 구조를 완성하는 동시에, 동부 외 사안들이 밀려 있다는 것을 처음으로 명시적으로 드러낸다.

## 핵심 질문

## 대신

리안: "상대가 움직일 자리를 남기십시오."
카르덴: "우리의 손실도 생각해야 합니다. 참고로 남부 재협상 건도 아직 답을 못 드렸습니다."

## 선택

- 지금처럼 왕실에 남아 보고를 받는다. (`royal_visit = false`, 기본)
- **직접 동부로 간다.** (`royal_visit = true`, Strong Choice)

## Major Branch — 왕이 직접 동부로 간다

## 현실 대응 가능성
여러 내적 기능이 정면으로 충돌하는 상태.

## Unity 연출
왕은 여전히 말하지 않는다. 네 대신이 서로 다른 위치에서 왕을 바라봄.

## Event 18′. 떠나는 채비 [동부·방문]

> `royal_visit=true`일 때 위 기본형을 대체. §5.1.4/§26 명세를 실제 프로즈로 채움(§31 TBD 해소).

### 표면 사건
왕이 직접 동부로 가기로 한 뒤, 실제 출발 준비가 시작된다. 사절을 보내는 것과 왕이 직접 떠나는 것은 준비의 규모부터 다르다.

### 드라마 목적
왕이 직접 가는 것 자체가 이미 강한 신호임을 보여준다 — 아직 국경을 넘기도 전에 이 결정은 이미 행동이다.

### 핵심 질문
> **직접 가겠다는 결정은 이미 어디까지 말해버렸는가?**

### 관찰 가능한 사실
- 수도를 비우는 기간 동안의 대리 통치 체계가 짜여야 함
- 수행 규모가 곧 동부에 보내는 첫 메시지가 됨(정식 행렬 / 최소 수행)
- 동부는 아직 왕의 방문을 공식 요청한 적 없음

### 대신
세르안: 대리 통치 체계부터 정리하겠습니다. 기록에 공백을 남길 수 없습니다.
발렌: 수도를 비우는 동안의 방비는 제가 맡습니다. 문제는 그쪽이 아닙니다.
리안: 행렬의 규모 자체가 먼저 도착하는 전언입니다. 무엇을 보내고 싶으십니까?
카르덴: 요청받지 않은 방문입니다. 그 점은 폐하께서도 아셔야 합니다.

### 선택
- 전례에 따라 정식 행렬을 갖춰 떠난다 (`eastPressure += 1`)
- 최소한의 수행만 데리고 떠난다
- 경호만 남기고 격식을 최대한 줄여 떠난다
- 일정을 미리 알리지 않고 떠난다

### 현실 대응 가능성
격식을 갖춰 찾아가는 것 / 조용히 찾아가는 것 / 예고 없이 나타나는 것.

### 금지
"동부가 이 소식에 놀랐다/기뻐했다" 같은 상대 속마음 확정 금지. 아직 국경 너머의 반응은 관찰되지 않은 사실이다.

### Unity 연출
행렬 규모에 따라 다른 출발 장면. 왕은 여전히 대사가 없다.

# Event 19. 조건을 바꾼 상대 [남부] — 신규

## 드라마 목적

## 관찰 가능한 사실

- 남부 측 문의가 도착함

## 대신
카르덴: "지난 두 달 동안 동부 문제로 열린 회의가 열한 번입니다. 남부 수로 공사는 아직 첫 회의도 끝나지 않았습니다."

## 생활 NPC

## 선택

- 담당자에게 위임한다.
- 동부 문제 정리 후로 미룬다.

## 현실 대응 가능성
한 관계에 몰두하는 동안 방치된 다른 일/관계.

## Unity 연출

왕이 실제로 동부 국경에 도착한다. 입국이 지연되거나 제한된다는 사실을 보고서가 아니라 눈으로 직접 본다. 적대 선언은 여전히 없다.

### 드라마 목적
직접 보는 것이 확신을 주지 않는다는 것을 보여준다 — 관찰이 늘어도 해석은 여전히 왕의 몫으로 남는다.

### 핵심 질문
> **직접 보고도 확신할 수 없다면, 그 불확실함을 안고 다음 행동을 정할 수 있는가?**

### 관찰 가능한 사실
- 성문 앞에서 실제로 기다리는 시간이 발생함
- 국경 관리들의 태도는 사무적이며 적대적이지 않음
- 왕이 직접 왔다는 사실 자체가 동부 쪽에도 이미 알려짐(반응은 아직 관찰되지 않음)

### 대신
리안: 선이 생겼다는 것과 적이 됐다는 것은 다릅니다. 여기 직접 서 계셔도 그 사실은 바뀌지 않습니다.
카르덴: 폐하를 이 자리에 이렇게 오래 세워둘 수는 없습니다.
발렌: 지금이라도 돌아가실 수 있습니다.

### 선택
- 성문 앞에서 기다린다
- 수행 규모를 줄여 다시 요청한다
- 돌아간다 (`eastWarmth -= 1`)
- 공식 사유를 요청한다

### Strong Branch
경계를 반복적으로 무시하면(같은 자리에서 규모를 줄이지 않고 계속 압박하면) 실제 외교적 긴장으로 확대될 수 있음 — 기본 루트와 동일한 위험.

### 현실 대응 가능성
직접 찾아갔지만 거절당하는 상황 / 그 자리에서 계속 기다리는 것 / 물러나는 것.

### 금지
"동부가 왕의 방문에 감동했다/불쾌해했다"는 속마음 확정 금지. 사무적 태도라는 관찰 사실만 유지한다.

### Unity 연출
닫힌 성문 앞에 실제로 서 있는 왕. 수행원들과의 거리로 고립감을 표현. 패배 음악 금지(기본형과 동일 원칙).

# Event 21. 국경의 오해 [북부] — 신규

> **발생 조건: `northTension >= 5` 이고 `north_hardline`(E07)이 설정된 경우에만.** 조건 미달이면 이 Event 전체가 스킵되고 "§5.1.5 안정된 국경" 브리지로 대체된다.

## 표면 사건
북부 국경에서 우리 측 순찰과 북부 측 병력이 근접하는 사건이 발생한다. 충돌은 없었으나 양측 모두 놀란다.

## 드라마 목적
반복된 애매함이 실제 위험으로 번질 수 있음을 보여준다 — 과잉 대응의 위험.

## 핵심 질문
> **오해가 실제 충돌이 되기 전에 멈출 수 있는가?**

## 관찰 가능한 사실
- 근접 상황 발생
- 발포 없음
- 양측 공식 항의 없음
- 현장 보고가 엇갈림

## 대신
발렌: "여기서 더 세게 나가면 진짜 전쟁이 됩니다."
리안: "지금 필요한 건 확인이지 경고가 아닙니다."
카르덴: "우리 병사들부터 진정시켜야 합니다."

## 선택
- 즉시 강경 대응
- 공식 채널로 해명 요구
- 현장 지휘관에 자제 지시
- 침묵 유지

## Strong Branch
강경 대응을 고르면 이후 북부 관계 전체가 긴장 국면으로 전환.

## 현실 대응 가능성
오해가 실제 갈등으로 번질 뻔한 상황, 과잉 반응의 위험.

## 금지
"북부가 침략 의도였다" 확정 금지.

## Unity 연출
국경 초소, 긴박한 신호음, 이후 정적.

# Event 22. 공물 [동부]

## 표면 사건

## 드라마 목적

## 핵심 질문
> **주는 행동이 상대의 반응을 요구하는 거래가 되고 있지는 않은가?**

## 선택
- 작은 답례
- 큰 공물
- 서신만 전달
- 아무것도 보내지 않음

## 후반 캐릭터 후보

## 현실 대응 가능성
선물 / 편지 / 감정적 투자.

## 금지
공물의 크기 = 진심의 크기.

## Unity 연출

## Event 22′. 직접 건네는 것 [동부·방문]

> `royal_visit=true`일 때 위 기본형을 대체(§31 TBD 해소).

### 표면 사건
공물을 대리인이 아니라 왕이 직접 건넨다. 대리인을 거치지 않는다는 것 자체가 이미 다른 무게를 갖는다.

### 드라마 목적
직접 건네는 행동이 선의를 증명하는 것이 아니라, 오히려 상대에게 더 명확한 응답을 요구하는 압박이 될 수 있음을 보여준다.

### 핵심 질문
> **직접 건네는 것이 진심을 보여주는 행동인가, 상대가 거절하기 더 어렵게 만드는 행동인가?**

### 선택
- 작은 것만 건넨다
- 준비한 만큼 그대로 건넨다 (`eastPressure += 1`)
- 사정을 한마디 덧붙이며 건넨다
- 말없이 건넨다

### 현실 대응 가능성
직접 만나 선물을 전하는 것 / 그 자리에서 설명을 덧붙이는 것 / 아무 말 없이 건네는 것.

### 금지
건네는 양이나 태도로 상대의 진심을 확정하지 않는다. 반응은 아직 관찰되지 않았다.

### Unity 연출
왕의 손에서 상대의 손으로 넘어가는 순간을 클로즈업. 선택은 여전히 추상적 행동이며, 실제 반응은 aftermath에서.

# Event 23. 마지막 회담 [동부]

> `royal_visit=true`면 "E23′ 그 자리에서"로 교체된다(§5.1.4, 프로즈는 아래 "Event 23′" 하위 섹션). 아래는 기본형.

## 표면 사건
동부와 중요한 직접 회담이 열린다.

## 드라마 목적
"상대의 마음을 바꾸는 게임"이 아니라는 사실을 가장 직접적으로 체감시킨다.

## 핵심 질문
> **결과를 통제할 수 없어도 내가 전달할 태도는 정할 수 있는가?**

## 선택 설계
왕의 긴 대사를 고르지 않는다. 행동 의도를 고른다.

예: 오해를 정리한다 / 미안했던 부분을 인정한다 / 더 요구하지 않는다 / 현재 관계 형태를 확인한다 / 자신의 경계를 전달한다.

정확한 대화 문구는 연출에서 전부 보여주지 않아도 된다.

## 상대 반응
관찰 가능한 말과 행동만. 속마음 내레이션 금지.

### 동부 측 실제 대사 (2026-09-19 작성, Ink `e23_reply_*` 반영)
동부 측 대표(이름/문화/국가명은 TBD)가 왕의 행동 의도에 답한다. 관찰 가능한 말과 행동만 쓴다.

| 왕의 행동 의도 | 기본형(사절 경유) | 방문형(대면) |
|---|---|---|
| 오해를 정리한다 | 서기관에게 받아 적게 한다. "전해 들었습니다. 저희 기록과 다른 부분은 정리해서 알려드리겠습니다." | 경위를 끝까지 듣는다. "지금 들은 내용을 저희 기록과 맞춰보겠습니다. 다른 부분이 있으면 오늘 안에 말씀드리죠." |
| 미안했던 부분을 인정한다 | 잠시 말이 없다. "그 부분은 기록에 그대로 남기겠습니다." | 잠시 말이 없다. "그 말씀은 기록에 그대로 남기겠습니다." |
| 더 요구하지 않는다 | "요청 사항 없음으로 정리하겠습니다. 이후 일정은 공식 경로로 알려드리겠습니다." | 동일 |
| 현재 관계 형태를 확인한다 | "지금 상태는 있는 그대로 문서에 옮기겠습니다. 뭐라고 부를지는 조약문에서 정하죠." (형태 결정은 E24로 넘김) | 동일 |
| 자신의 경계를 전달한다 | 서기관에게 받아 적게 한다. "전달받았습니다. 저희도 저희 쪽 경계를 같은 방식으로 정리해 두겠습니다." | "알겠습니다. 저희도 저희 쪽 경계를 같은 방식으로 정리해 두겠습니다." |

원칙: 수락/거절/호의를 확정하지 않는다(§30 4·6번). 어떤 답도 E24 관계 결과를 미리 정하지 않으며 수치 변화가 없다. 동부에 이름이나 특별한 어조를 주지 않는다(§30 18번, `05_multi_kingdom_relationship_routes.md`).

## 현실 대응 가능성
직접 대화 / 중요한 만남.

## Unity 연출
UI 최소화. 대신 의견은 회담 직전까지만. 왕의 음성은 아직 명확히 들려주지 않는 방향을 우선한다.

## Event 23′. 그 자리에서 [동부·방문]

> `royal_visit=true`일 때 위 기본형을 대체(§31 TBD 해소). §5.1.4: "회담이 서신이 아니라 대면으로 진행, 리안/카르덴의 경고 맥락이 실시간으로 바뀜."

### 표면 사건
동부와의 마지막 회담이 서신이 아니라 실제 대면으로 열린다. 대신들의 조언도 문서가 아니라 회담 직전, 그 자리에서 실시간으로 전달된다.

### 드라마 목적
기본형과 같은 사실을 보여주되, 완충 장치(서신, 시간차, 거리)가 사라졌을 때 그 결과를 통제할 수 없다는 감각이 얼마나 더 즉각적인지 체감시킨다.

### 핵심 질문
> **완충 장치 없이 마주해도, 내가 전달할 태도는 여전히 내가 정할 수 있는가?**

### 선택 설계
기본형과 동일한 행동 의도 선택지를 그대로 쓴다 — 다른 것은 전달 방식(서신 vs 대면)이지 의도의 종류가 아니다.

예: 오해를 정리한다 / 미안했던 부분을 인정한다 / 더 요구하지 않는다 / 현재 관계 형태를 확인한다 / 자신의 경계를 전달한다.

### 대신 (회담 직전, 실시간)
리안: 지금부터는 제가 대신 전할 수 없습니다. 표정도, 말투도 전부 폐하의 것입니다.
카르덴: 물러설 자리를 남겨두십시오. 마지막에도 그건 유효합니다.

### 상대 반응
관찰 가능한 말과 행동만. 서신일 때보다 반응까지의 시차가 없다는 것 자체가 차이지만, 속마음 내레이션은 기본형과 동일하게 금지. 실제 대사는 위 Event 23 "동부 측 실제 대사" 표의 방문형 열을 따른다.

### 현실 대응 가능성
글이 아니라 얼굴을 보고 나누는 대화 / 도망칠 곳 없는 중요한 만남.

### Unity 연출
UI 최소화, 기본형보다 카메라 거리를 더 좁힘. 왕의 음성은 여전히 들려주지 않는다.

# Event 26. 전후 복구 [전체]

> 다국가 구조의 payoff. 설명 대신 지도로 보여준다.

## 표면 사건
동부 문제가 중심에서 내려오자 그동안 미뤄졌던 왕국 내부 문제와 다른 나라와의 관계가 눈에 들어온다.

## 드라마 목적
"동부는 세계 전부가 아니었다"를 설명이 아니라 장면으로 보여준다.

## 핵심 질문
> **관계 밖의 삶으로 다시 돌아갈 수 있는가?**

## 관찰 가능한 사실
- 서부와의 정기 지원 회담이 다시 열린다(Event 09 회수). **`westWarmth <= 7`면 "아직 데면데면하지만 회담 요청은 왔다", `westWarmth >= 9`면 "예전처럼 편하게 회담이 다시 열렸다"** — 둘 다 평가 아님(§25).
- 남부 상단이 돌아오고 수로 공사 회의가 재개된다(Event 05, 19 회수) — `south_hardline`으로 E19가 스킵됐던 경우, 여기서 대신 "끊어진 상단이 다시 문을 두드렸다" 한 줄로 처음 재접촉이 이뤄진다.

## 27.1 등장·해금·장면 참석 조건

`introduced`는 플레이어에게 실제 소개되었음을 뜻한다. `unlocked`는 등장 가능한 상태이며 소개/참석과 다르다. 장면 참석은 실제 장소·보고 채널에 맞게 따로 판단한다. 해금만으로 모든 대사에 인물을 넣지 않는다.

| 캐릭터 | 최초 소개/조건 | 이후 대사 조건 |
|---|---|---|

예시(문서): **외교관 등장 완료 + 회의 참석 → 리안 대사 / 미등장 → 해당 의견 생략**. Ink는 `{ rian_introduced: 리안: ... }`를 사용하며, 방문 루트(Event 18′/20′/22′/23′)도 동일한 조건문 패턴을 그대로 따른다 — E17 시점엔 세르안/발렌/리안/카르덴이 모두 이미 소개된 상태라 실질적으로 항상 참이지만, 등장 순서가 바뀔 경우를 대비해 조건문 자체는 유지한다.

# 30. Story Do Not Drift

1. 왕은 회의 참가자가 아니다.
2. 왕은 마지막까지 직접 말하지 않는다.
3. 선택은 행동이다.
4. 상대의 진짜 마음을 공개하지 않는다.
5. 친절을 사랑으로 확정하지 않는다.
6. 침묵을 거절로 확정하지 않는다.
7. 사실 자체를 감정 상태 때문에 바꾸지 않는다.
8. 대신은 서로 다른 렌즈다.
9. 강한 선택은 실제 분기를 만든다.
10. 플레이어 동기를 게임이 설명하지 않는다.
11. 특정 실제 인간관계를 Canon 정답으로 복제하지 않는다.
12. 2회차는 정답 풀이가 아니다.
13. 엔딩은 설명보다 이미지와 구조로 전달한다.
14. `KING WAS YOU`는 발견.
15. `KING WAS ME`는 선언.
16. 마지막 명확한 왕의 대사는 **"내가 결정하지."**
17. **왕국 사건은 인간관계 은유를 제거해도 독립적인 왕국 사건으로 성립해야 한다** (WORLD-FIRST METAPHOR RULE).
18. **동부 왕국은 처음부터 특별한 국가가 아니다 — 반복이 특별하게 만든다** (EASTERN KINGDOM RULE).
19. **한 관계에 집중하는 동안에도 세계의 다른 사건은 계속 움직인다** (WORLD CONTINUES RULE).

# 32. 최종 Story Canon 요약

전체 이야기는:

> 작은 결정을 배우는 왕
> → 여러 이웃과의 관계를 동시에 관리하는 법을 배움
> → 그중 새로운 관계(동부)에 점점 의미를 붙이기 시작함
> → 불확실성을 견디기 어려워짐
> → 행동과 경계 사이에서 여러 선택을 함
> → 상대의 결과를 통제할 수 없음을 경험함
> → 자기 왕국의 삶 — 그리고 다른 모든 관계 — 으로 돌아옴
> → 새로운 가능성을 다시 마주함
> → 자신의 자리로 직접 걸어감

으로 이어진다.

이 이야기의 결론은 **상대를 정확히 읽는 능력**이 아니다.

> **모든 목소리를 듣고도, 최종 결정을 내가 내리는 능력**

이다.

마지막으로 왕이 말한다.

> **"내가 결정하지."**

그리고 마지막 타이틀.
